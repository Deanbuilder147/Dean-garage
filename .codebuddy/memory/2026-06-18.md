## 修复: Canvas containment + CSS尺寸约束 (2026-06-18/19 午夜)

### 根因
- `.game-canvas-sandbox { contain: layout size; }` 的 `size` 关键字导致浏览器对子元素溢出全盲，overflow/scrollbar 失效

### 修复（联动 P0+P1）

## 修复: 拖拽失效 — canvas.onxxx → window.addEventListener (2026-06-19 00:10)

### 根因
max-width:100% 约束后 canvas 不再溢出撑满沙盒，拖拽时鼠标容易移出 canvas 元素：
- `canvas.onmouseleave` 立即设 `isDragging=false` → 拖拽中断
- `canvas.onmouseup` 不触发（鼠标已移出） → cursor 卡在 grabbing

### 修复
- mousedown 时在 window 上注册 _windowDragMove/_windowDragEnd（外部 let 变量保存引用）
- window mouseup 中 removeEventListener + 恢复 cursor
- canvas.onmousemove 只做 hover 检测（`if (isDragging) return`）
- canvas.onmouseleave 只清 hoverCoord，不重置 isDragging
- 所有 canvas.onxxx 改为 addEventListener（统一风格）

- 构建: 112模块, 0错误
- Bundle: index-LVCqmmPz.js
- 容器: Healthy / HTTP 200
