## 修复: 战场坐标错位 + 编辑器拖拽失效 (19:00)

### 问题1: NewBattleView.vue - 缩放/平移后鼠标高亮错位
**根因**: `canvasPosToWorld()` 返回 `{ x: worldX, y: worldY, q, r }`，其中 `worldX/worldY` 是等距（ISO）逆向**之前**的值。后续 `pixelToHex(wp.x, wp.y)` 将未逆ISO矩阵的值传入 `pointyTopToHex`，双重错误导致缩放/平移后坐标映射偏离。

**修复**: 
- `canvasPosToWorld` 返回 `{ x: flatX, y: flatY, q, r, wx: worldX, wy: worldY }`（x/y = ISO逆向后坐标）
- wheel handler 缩放: `worldPos.x/y` → `worldPos.wx/wy`（需前后值保持 screen=fixed 约束）
- zoomIn/zoomOut: `worldCenter.x/y` → `worldCenter.wx/wy`

### 问题2: NewBattlefieldView.vue - 编辑器无法拖拽/缩放
**根因**: 使用旧 `canvas.onmousemove/onmouseleave/onmouseup` 模式。鼠标移出 canvas → `onmouseleave` 重置 `isDragging` → 拖拽中断，且 `mouseup` 不触发 → cursor 卡死。

**修复**: 改为 `addEventListener` + window 级 drag 模式:
- 新增 `_windowDragMove/_windowDragEnd` 外部变量
- `mousedown` → `window.addEventListener('mousemove/mouseup', ...)`
- `mouseleave` 只清 hoverCoord，不再重置 isDragging
- `onwheel` → `addEventListener('wheel', ...)`
- 所有 `canvas.onxxx` → `canvas.addEventListener(...)`
