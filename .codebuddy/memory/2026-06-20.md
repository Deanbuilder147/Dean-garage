## 宪法级修正：Canvas CSS 物理尺寸死锁 + JS 动态尺寸污染切除 (12:34)

### 问题根源
HexGridCanvas.vue 中 JS 代码通过 `canvas.width = cw; canvas.height = ch;` 将 Canvas 物理尺寸设置为世界坐标尺寸（grid 越大 canvas 越巨大），严重违反《战棋开发终极宪法 v2.0》沙盒边界隔离红线：
1. `computeCanvasSize()` 根据网格尺寸计算 `cw`, `ch`，在 `initCanvas()` 和 `draw()` 中写入 canvas 属性
2. `draw()` 每帧检查 `canvas.width !== cw || canvas.height !== ch` 并 resize
3. `.canvas-container` 和 `<canvas>` CSS 无固定尺寸约束，自由跟随 JS 赋值膨胀

### 5 处宪法修正
| # | 位置 | 改动 |
|---|------|------|
| 1 | CSS `.canvas-container` | 新增 `width: 100%; height: 100%` |
| 2 | CSS `canvas` | 新增 `width: 100%; height: 100%` |
| 3 | JS | 删除整个 `computeCanvasSize()` 函数 |
| 4 | JS `initCanvas()` | `canvas.width = container.clientWidth; canvas.height = container.clientHeight`（锁死为容器像素尺寸） |
| 5 | JS `draw()` | 删除 `const { cw, ch } = computeCanvasSize()` 和 resize 块，仅保留 `centerGrid()` |
| - | JS `zoomReset()` | 内联世界范围计算（仅用于 fitScale，不污染 canvas 物理尺寸） |

### 宪法红线
- CSS 物理尺寸：`.canvas-container` 和 `<canvas>` 写死 `width:100%; height:100%`，绝不改变
- JS：canvas.width/height 只在 init 时设置一次 = 容器 client 尺寸
- 所有缩放/平移：纯 CTM 变换（ctx.translate + ctx.scale），canvas 元素本身尺寸永不变化
