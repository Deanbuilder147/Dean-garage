## Phase 9.6: 紧急修复 3D 倾斜 X 轴失效与首行倾斜

**问题**: Phase9 CTM `transform(scaleX, shearY*scaleX, 0, scaleY)` 严重缺陷:
1. shearX 从矩阵移除 → X 轴滑块完全无响应
2. screenY = scaleY*flatY + shearY*scaleX*flatX → R=0 行因 flatX≠0 发生视觉倾斜

**修复 (HexGridCanvas.vue, 5处)**:
1. 正向 CTM: `transform(scaleX, 0, shearX, scaleY, 0, 0)` — shearX 回归
   screenX = scale*(scaleX*flatX + shearX*flatY) + offsetX
   screenY = scale*(scaleY*flatY) + offsetY  ← 锁死: 仅依赖 flatY
2. 逆矩阵: flatY=worldY/scaleY, flatX=(worldX-shearX*flatY)/scaleX
3. centerGrid: isoCenterX += midGrid.y*shearX, isoCenterY = midGrid.y*scaleY
4. zoomReset ch: 移除 shearY 依赖
5. 注释: Phase9.6 标准等距平行投影

**数学验证**:
- R=0 行: flatY=0 → screenY=offsetY (绝对水平) ✓
- 6/6 正逆往返测试通过 ✓
- shearX=0.25 → R=5 偏移 36.32, R=10 偏移 135.00 (线性纵深感) ✓
- 列斜率恒定 = shearX*scaleY/(scaleX*sqrt(3)) ✓
