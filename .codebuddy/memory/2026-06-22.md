1. **CampaignView.vue apiCall 硬编码**: `API_BASE = 'http://localhost:3004/api'` — 浏览器直连 localhost:3004，绕过 Nginx 代理，生产环境必然失败

## Phase 20-C: 空间主权夺回 — 暴力锁死 Canvas 高度 (11:05-11:11)

### 故障根因
剧情模式下 `.dm-battle-layout` 的 `height: 100vh` 与父级 CampaignView 的 `flex: 1` 形成冲突。`.campaign-battle-container` (h-screen flex-col) → header + narrative (shrink-0 ≈ 100px) → NewBattleView (flex:1) → 子组件 dm-battle-layout 自持 100vh 导致溢出被裁剪，Canvas 塌缩至 248px。

### 修复方案
CampaignView.vue `<style scoped>` 追加 `:deep()` 穿透样式，用 `!important` 暴力锁死：

| 目标 | 规则 |
|------|------|
| `.campaign-battle-container` | `height: 100vh !important; max-height: 100vh !important; overflow: hidden !important; display: flex !important; flex-direction: column !important` |
| `:deep(.dm-battle-layout)` | `height: 100% !important; min-height: 100% !important; flex: 1 !important; display: flex !important` |
| `:deep(.dm-main)` | `height: 100% !important; flex: 1 !important; display: flex !important; flex-direction: column !important; overflow: hidden !important` |

### 高度链运算
```
campaign-battle-container = 100vh (768px)
  header + narrative = ~100px (shrink-0)
  NewBattleView = flex:1 = 668px
    dm-battle-layout = 100% = 668px (覆盖 100vh)
      dm-main = 100% = 668px - 40px(header) ≈ 628px
        HexGridCanvas → Canvas 628px+ ✅
```

## Phase 21: 绝地清障 ─ [object Object] UUID 类型冲突 + 123 级联错误归零 (11:12-11:20)

### 故障根因
