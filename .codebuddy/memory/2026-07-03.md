## Phase 30 紧急热修复：解除 Canvas 矩阵双重挤压 (2026-07-03 第三部分)

### 问题诊断
上一轮 Phase 30 Item 7 修复将 ISO shear 参数放入 `ctx.transform()` 中，导致与 hexUtils 2D 坐标计算发生叠加，产生严重拉伸畸变。

### 架构重构：物理剥离
**核心原则**: Canvas 变换矩阵永远只负责 scale(缩放)+translate(平移)，ISO 等距变换由 hexUtils.js 逐顶点精确施加。

### hexUtils.js 新增函数
- `isoTransformPoint(px, py, iso)` — ISO 正向变换（2D→ISO屏幕坐标）
- `isoInverseTransformPoint(px, py, iso)` — ISO 逆向变换（ISO→2D，用于点击反算）
- `drawIsoHexPath(ctx, cx, cy, iso)` — 逐顶点 ISO 变换绘制等距六边形路径
- `drawIsoHexPathDeformed(ctx, cx, cy, cellW, cellH, topFlat, bottomFlat, iso)` — ISO 扁六边形路径

### HexGridCanvasEngine.vue 重构
1. **`draw()` CTM 纯净化**: `ctx.transform(ISO.scaleX, ISO.shearY, ISO.shearX, ISO.scaleY, 0, 0)` → `ctx.setTransform(scale, 0, 0, scale, offsetX, offsetY)` — b 和 c 强制为零
2. **`canvasPosToHex()` / `canvasPosToWorld()`**: 使用 `isoInverseTransformPoint()` 替代内联 2×2 逆矩阵
3. **`centerGrid()`**: 使用 `isoTransformPoint()` 替代局部 `isoTransform()`
4. **`getGridDims()` / `zoomReset()`**: 使用 `isoTransformPoint()` 计算精确 ISO 视觉边界（修复 gridH 遗漏 shearY 项）
5. **`renderTerrainCache()` / `renderTerrainInline()` / `renderHighlights()`**: 全部切换为 `drawIsoHexPath()` / `drawIsoHexPathDeformed()`，文本标签使用 `isoTransformPoint()` 对齐
6. **`drawFn` 向后兼容**: 通过局部 `ctx.save/transform/restore` 临时施加 ISO，同时传递 `iso` 对象到 context
