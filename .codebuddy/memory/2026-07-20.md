## 修复：createBattle 404 BATTLEFIELD_NOT_FOUND
- 现象：浏览器 `POST /api/combat` → 404（`createBattle failed: 404`）
- 排查关键：无 token 的 curl 被 authenticate 拦在 401，误以为路径/代理问题；实际带 token 后网关走到 DB 查询 `maps WHERE id = ?`，因前端硬编码 `battlefield_id: 1` 而数据库地图用 UUID（唯一战场 `a4eba9f1-ff74-4536-baf7-710801bac871`）→ 404。
- 根因：`frontend/src/views/NewPreparationRoom.vue:270` 硬编码 `battlefield_id: 1`。
- 修复：改为房间真实 mapId `room.value?.room?.mapId || room.value?.mapId || 1`。
- 部署：SCP 到服务器 `/root/mecha-universe-engine/frontend/src/views/`，`cd frontend && npm run build`，`docker compose build frontend && docker compose up -d frontend`。新 bundle `index-B5OxQzld.js` 已含 mapId 逻辑，容器已重建启动。
- 经验：401 是 authenticate 拦截，真正 404 在带 token 的 DB 查询阶段，勿被 401 误导。
