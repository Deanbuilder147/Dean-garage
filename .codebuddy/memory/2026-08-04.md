## 2026-08-04 地图炮保存链路验证 + deepMerge 类型污染根治（已部署）

**用户问题**：怎么确认绘制模式下画的打击范围被正确保存了？

**验证过程中发现并修复的真实 bug（3 处）**：

### 1. deepMerge 数组/对象类型混合污染（根因，`configLoader.cjs`）
- 原实现：`if (source[key] 是对象) result[key] = deepMerge(result[key] || {}, source[key])`
- 当磁盘旧值是**数组** `[[0,0,0]]`、新值是**对象** `{right:[...]}` 时，`{...[[0,0,0]]}` 展开成 `{"0":[0,0,0]}`，与新对象合并产出**永久脏键**，且 deepMerge 语义下无法删除。
- 修复：函数入口加 `if (Array.isArray(target) !== Array.isArray(source)) return source;`，且仅当**新旧都是纯对象**时才递归，否则整体替换。这是通用正确性修复（不止修地图炮）。

### 2. `normalizeSkillForSave` 增加 map_cannon 结构规范化（`glossary.ts`）
- 统一 `directions` 为唯一合法形态 `{ [dirKey]: [{q,r}] }`，兼容旧扁平数组 `[[q,r,layer]]`（归入首方向），只认 6 个合法方向键、其余脏键丢弃。

### 3. 前端保存回写（`GlossaryHub.vue`）
- `syncRangeToSkill()` 把 `range.mcShapes` 按 MC_DIR_KEYS 写回 `draft.map_cannon.directions`。

**踩坑教训**：
- 曾尝试「`_delete_skills` 先删再写」→ 时序错乱导致数据丢失；又尝试「写盘后定点覆写 `writeGlossaryConfigRaw`」→ 因 `getGlossaryConfig()` 读到的已是 deepMerge 退化结果，反而覆盖正确数据。**正解是修 deepMerge 本身，不要在调用侧打补丁**。
- 用 `Object.keys(d)` 检查数组会得到 `["0"]`，极易误判为「对象脏键」，应先 `Array.isArray()` 区分。
- 排查权限时：`deantest` 是 role=user，PUT 词条需 admin+ 会 403；管理员账号 `dean147`(dominator)。测试可用 `docker exec mecha-gateway node -e 'jwt.sign(...)'` 借 `process.env.JWT_SECRET` 自签 token（注意默认过期时间，401 AUTH_TOKEN_EXPIRED 别误判为逻辑失败）。
- 存储A 物理路径：容器内 `/app/services/combat-service/src/config/glossary-skill-config.json`；宿主机 sqlite 在 volume `mecha-universe-engine_gateway_data/_data/mecha-universe.db`（容器内无 better-sqlite3，需在宿主机用 python3 读）。

**最终验证（端到端闭环全绿）**：
- PUT → `success=true`；GET 回读 `type=OBJECT`、`right=[{q:9,r:8},{q:10,r:8}]`、`rightup=[{q:9,r:7}]`

## 2026-08-04 词条编辑器保存失败(请先登录) 修复（已上线）

**现象**：GlossaryHub 编辑词条点「✓ 完成」→ 弹「保存失败：请先登录」，且编辑内容看似丢失。

**根因(两层)**：
1. **401 真因**：`GlossaryHub.vue` 第56行用**裸 axios**(无拦截器)调 `PUT /hub-config/:key`(glossary.ts 430行带 `authenticate`)。裸 axios 不注入 `Authorization`，后端 `authenticate` 无 token 返 401 `message:'请先登录'`（auth.ts:78）。GET 能加载因 GET 端点公开。
2. **误丢编辑**：旧 `toggleEdit` 是 `saveCurrent()`(fire-and-forget 无 await/catch) + 无条件 `editing=!editing`，保存失败仍退出编辑态，用户误以为编辑没了。

**修复**：
- `GlossaryHub.vue`：裸 axios → `apiClient`(自动带 `localStorage.token`)；`toggleEdit` 改 `await saveCurrent()` + catch 失败保留 `editing` 态。
- `api/client.js` 拦截器 + `main.js` `bootToken`：token 读取兼容 `localStorage.user.token` 兜底(虽 userStore.setToken 已写 localStorage.token，兜底防错位)。
- 测试号 deantest 是 **referee**，PUT 端点 `isAdminOrAbove`(glossary.ts:116 仅 ADMIN/DOMINATOR) 拦截 → 403「仅管理员可编辑」。所以 admin 修复后即能存，referee 仍 403(设计如此非 bug)。
