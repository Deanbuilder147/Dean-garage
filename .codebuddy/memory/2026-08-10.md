## 词条库 HexCanvasEditor 菱形 bug 根治
- 根因：`drawRange` 底网格用 `Math.abs(q+r)>R`（axial 坐标判定）圈格子，但渲染 `hexToPixel` 是 Even-R offset，混用导致范围被斜切成菱形。
- 修复（`frontend/src/components/glossary-editor/HexCanvasEditor.vue`）：
  - `drawRange` 判定改为 `hexDistance(0,0,q,r) <= rangeMax`（Even-R 真六边形范围）；补 import `hexDistance`。
  - `initCamera` 拍脑袋尺寸估算 → 新增 `fitCameraTo(cells)` + `viewCells()`，与地图编辑器同款 4 角包围盒+1格边距 fit 居中；五视图(hexsix/graph/range/aoe/map)统一复用，外观与地图编辑器一致。
  - 六边形形状本就 `drawHexPath` 没问题，只修坐标系与相机。
- 用户意图：射程/AOE/地图炮=纯六边形范围不铺整板；五视图全部统一成同款 Even-R 六边形蜂窝+居中相机。
- 部署：rsync→服务器 npm run build→docker compose build --no-cache mecha-frontend + up -d（端口 8081）。

## 缩放时格子间距漂移修复（第二版）
- 现象：滚轮缩放时格子间距变（放大稀疏、缩小重叠）。
- 根因：`drawHexPath(ctx,cx,cy)` 用固定 `HEX_RADIUS` 画六边形，但格心 `hexToScreen` 已按 `scale` 缩放 → 六边形不随 scale 变。
- 修复：`hexDraw.js` 的 `drawHexPath` 增可选 `radius` 参数（默认 HEX_RADIUS 保兼容）；`HexCanvasEditor.vue` 5 处调用、`GlossaryHubNew.vue` 战场 1 处调用均传 `HEX_RADIUS * scale.value`。六边形与格子间距等比缩放，间距恒定。
- 部署同上流程，验收：线上与容器内 `index-BRDMF3uq.js` MD5 一致（242f4343...）。已上线 8081。
