## 部署流程（重要，已踩坑）
- 前端 Dockerfile 只 `COPY dist`，**不编译**。部署必须：① rsync `frontend/src` → 服务器；② 服务器 `cd frontend && npm run build` 生成新 dist；③ `docker compose build mecha-frontend`（此时 COPY dist 不会 CACHED）；④ `docker rm -f mecha-frontend && docker compose up -d --no-deps mecha-frontend`（勿用 plain up，会与已存在的 mecha-battle-db 容器命名冲突）。
- compose 服务名是 `mecha-frontend`（不是 `frontend`）。
- 验证：线上 HTML `curl localhost:8081 | grep index-*.js` 的 hash 应与本地 build 一致。
