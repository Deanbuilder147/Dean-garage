galaxy-btn 星云按钮

旋转锥形渐变（conic-gradient）构成的"星云描边" + 内部星点漂移。 纯 CSS 动画，不依赖 anime.js。悬停可看到描边加速旋转、星点变亮漂移、图标右移微旋。
核心

三层 z-index 堆叠

::before（z0）= 旋转的锥形渐变；::after（z1）= 与背景同色的内遮罩， 盖住中间只留边缘 → 形成"描边"；__stars（z1）= 星点；__content（z2）= 文字与图标。 顺序不可乱，否则内容会被遮罩盖住。

动画

rotate-nebula 旋转

锥形渐变本身无法直接动画角度（除非用 @property 声明 --ang）， 这里改用整层旋转：transform: rotate(0→360deg) 4s 线性循环。 悬停时 animation-duration: 2s 提速一倍。

细节

星点用多重 radial-gradient

三个 radial-gradient 各画一个白点（1px / 1px / 0.5px）， background-size: 120% 放大后随 star-drift 缓慢缩放位移， 制造"星空缓慢流动"的错觉。悬停时 opacity 0.3→0.8 点亮。

注意

overflow:hidden 与 blur 的冲突

按钮设了 overflow: hidden，而 ::before 带 filter: blur(8px) —— 发光会被裁剪在按钮内，外部看不到光晕。 如需外溢光晕：去掉 overflow 并用外层 drop-shadow 补光（见上方"外溢光晕"变体）， 代价是 ::before 的 inset:-4px 会真正溢出，需要 wrapper 承接。

可维护

全 em 单位 + CSS 变量

padding / border-radius / gap 全部 em，因此只改 --btn-font-size 即可整体等比缩放，无需重算任何像素值（见大/标准/小号三档）。 配色同理，只覆盖 --btn-primary/secondary/accent 三个变量即可换主题。

无障碍

键盘可达

已含 :focus-visible（2px 描边 + 4px 偏移，仅键盘触发不干扰鼠标）与 :active 缩放反馈。图标用 aria-hidden 隐藏，文本即为可访问名称。
