## 一、六段归属与原子总览

```
WHEN(时机) → IF(条件) → ROLL(随机性) → DO(执行) → AFTER(后效) → COST(代价)
```
- `WHO` 段已删除，降级为 `DO` 段首置前导原子 `B_TARGET`。
- `AFTER` 收口持续状态/链式/清理。
