## 一、宏大愿景：通用战棋规则母体引擎

（来源：战棋策划文档.md · 用户口述的产品定位，非具体玩法，但统领所有功能）

- **元数据驱动一切规则**：一套引擎地基通过 Metadata 配置即可复刻一切 TRPG / 跑团 / 战棋题材（机甲 → 战锤40K → 龙与地下城），"一套地基，吞噬一切规则"，不推倒重来。
- **解决线下跑团算伤地狱**：玩家不再手算 Excel 自动卡、手投骰子、依赖 DM 肉眼判定；系统自动结算，一局从数小时压缩到流畅。
- **实体模型数字化工厂**：玩家手涂的真实塑料模型拍照（前/后/左/右四视角）→ 智能表单 + 趣味引导 → 30 秒蜕变为带 16 帧动画、0-6 七视态的数字棋子。
- **规则包一键换装热更新**：Dominator 后台上传 RuleManifest.json，前后端内存动态切换 KV 映射，**不重启任何容器**秒变新游戏。
- **不可变地图焦土沙盒**：地图存为服务器不可变资产；开战瞬间注入 battle_id 深拷贝，激光轰塌高山、剧情破坏桥梁只改写局内沙盒，战局销毁后原始 JSON 绝对不被污染。

## 二、账号与权限系统（四级）

（来源：战棋策划文档.md 功能列表 1 + 记忆 2026-07-31 账号自服务）

- 🔑 **游客层（Guest）**：免 Token 柔性放行；试玩战役、输入房号延迟观战；编辑器支持 LocalStorage 本地暂存，登录后一键同步云格纳库。
- 👤 **普通用户（User）**：完整私人格纳库与对战；上传资产需管理员审核；每日 AI 生成积分扣减锁；累积对局可升"裁判"。
- ⚖️ **裁判（Referee）**：创建联机房间、设置房间内容独裁权；局内无延迟强制全屏上帝视角裁决（区别于微信观战）。
- 🛡️ **管理员（Admin）**：审核队列 5 分钟自动过期防撞锁；创作者授权下可一键物理深拷贝私人棋子为官方公共资产包（保留版权勋章）。
- 👑 **Dominator（总监）**：最高统帅权，封禁账号、撤/设管理员。
- 📋 **功能权限矩阵**（第七章节，T4 落地）：后端 `feature_permissions` 表 + `DEFAULT_FEATURE_PERMISSIONS`，`requireFeature` 中间件按角色放行；dominator 硬编码逃生通道。`glossary.edit` / `glossary.excel` / `units.edit` / `maps.edit` 等细粒度授权。
- ✅ **账号自服务**（已落地）：改资料（username/email/faction，UID 不可改）、改密码（bcrypt 验旧 ≥6 位）；侧边栏头像弹窗含 UID 展示（标注不可改）。

## 三、战斗系统

（来源：策划文档场景 + 记忆 2026-07-31~08-02 战斗体验反馈 + 射程/阵营架构记忆）

### 3.1 技能与自然语言规则引擎
- 🎲 **语言学语法树组装**：非编程人员像拼乐高一样组装"主谓宾定状补"自然语言句子（"我专注射击左上第4格目标；定语：舍弃移动；状语：投1d6=6；补语：+5能量伤害"）→ 秒变大一统抽象语法树 JSON，战斗引擎无状态执行。
- 🧩 **定状补断言状态机**：一个词条可挂载代价层 + 投骰层 + 多级负面分流层动态串联；`MAX_LOOP_STEP=10` UGC 沙盒拦截 + 最外层 try/catch 兜底，真机永不假死。
- 🔗 **层叠与冲突管理器**：算伤管道内对并发词条分配层叠权重与互斥矩阵，杜绝 Buff 覆盖冲突死锁。
- 📋 **五谓语技能**（已落地 skillExecutor v5）：attack / heal / buff / debuff / passive 统一 switch，词条 JSON 驱动。

### 3.2 阵营 × 角色双语义（用户核心设计纠正）
- 🐞 **用户点出核心 bug**（2026-07-31）：战斗内 `faction` 被 overloaded——固有阵营（earth/maxion/balon，展示用）与轮转角色（attack/defense/ambush，逻辑判定唯一依据）必须剥离。
- ✅ **硬解耦落地**（方案A）：BattleUnit 增 `role`；敌我 / 掩护 / ZOC / 可见性 / 胜负 / 技能发放**全部按 `unit.role` 判定**，禁止直接比 `unit.faction`。`factionSkillRegistry` 按角色发"攻击/防守/偷袭"技能。
- 🐞 **隐匿拨乱反正**（已修）：隐匿资格本误绑固有 faction=maxion（防守方），用户预期应属 **ambush（偷袭方）**；改为 `resolveRole()==='ambush'` 判定。
- 🔶 **奇袭（反应奇袭）**：前后端完整实现（QTE 弹窗 + 暗绿滤镜 + 轮询 pendingSurprise）；用户反馈"没提示"待构造对局实测联动。

### 3.3 射程与攻击
- ✅ **射程单一真相源**（Phase 31）：`DEFAULT_RANGE_BY_CATEGORY` 只在 shared-kernel 维护，远程唯一值=3；前端逐字镜像。字段优先级 `cast_range ?? max_range ?? range_max ?? range`。
- ✅ **普通攻击已彻底删除**（Phase 32，2026-08-03）：攻击完全由机体**真实携带技能**承载，无隐式 basic_attack；网关 `/attack` 无 skill_id 返回 400 `SKILL_REQUIRED`。
- ✅ **AP 行动点**（已落地）：`DEFAULT_ACTION_POINTS={MOVE:1,ATTACK:1,DEFEND:1}`，用满任意两类即 standby；行动画板四按钮（移动机动/战术行动/防御/待机）。

### 3.4 战场视觉与质感（用户走完一局反馈，已批量修）
- ✅ **像素锐化**：绘制时 `imageSmoothingEnabled=false`，S/M/L/XL 放大保持硬朗像素边缘。
- ✅ **死亡结算**：hp≤0/dead 单位幽灵清理（不绘制）+ 卡片置灰删除线 + 血条 0.3s 过渡（消除扣血瞬变）。
- 🔶 **结算 overlay 残余血条**：原 victory-overlay 仅显 winner/condition/message，双方残余 HP 显示待补（用户未单独要求）。
- ✅ **七视图渲染优先**：棋子形象 4 级降级 = 七视图 > 精灵 > 阵营Logo > 矢量圆；上传七视图即按七视图渲染（修复 view_urls 注入后上线）。
- ✅ **坐标层级**：绘制按 screenY 升序，row/col 越大越靠前，满足需求。

### 3.5 战局持久化（用户拆分三步根治重启丢失）
- ✅ **快照系统全上线**（2026-08-01）：battles 表加 `state_snapshot`；combatSnap 序列化/反序列化/reconcile；44 处 `battleStore.get` → `requireBattle` rehydrate；终局清快照防 SQLite 膨胀；WS 重连强刷。
- 🔶 **recall-unit 独立路由**：计划列有 recall-unit 落库，但全代码库无独立路由（仅 Royroy 回收复用 deploy 落库），待用户确认是否补 `POST /recall-unit`。
