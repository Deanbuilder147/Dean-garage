## 1. 坐标系定义（共识）

| 概念 | 取值 | 说明 |
|---|---|---|
| 坐标表示 | `(q, r)` | Even-R Offset（尖顶，偶数行右移半格） |
| 列 | `q` | 列方向 |
| 行 | `r` | 行方向；`r % 2 === 0` 为偶数行，整体右移半格 |
| 立方第三轴 | `s = -q - r` | 仅用于距离/共线计算，不存储 |
| 像素尺寸常量 | `HEX_WIDTH=64, HEX_HEIGHT=72` | 统一从 hexUtils 导入，严禁硬编码 |

坐标 Key 唯一真相源（前后端同构）：
- 前端 `getHexKey(q, r)` → `q + ',' + r`
- 后端 `hexKey.cjs` `getHexKey(q, r)` → `q + ',' + r`
- 后端 map-service `HexUtils.hexKey` → `` `${q},${r}` ``

**严禁**混用 `${q}_${r}`、反引号模板等写法，否则地形 Key 拼写漂移导致静默回退 `moon`。

## 2. 距离真理副本 A：map-service.HexUtils.hexDistance（被寻路调用）

位置：`mecha-universe-engine/services/map-service/src/utils/hexUtils.js:85`

```js
hexDistance(q1, r1, q2, r2) {
  // ★ 阶段 B：Even-R offset 语义统一（offset→axial 后取 cube 距离）
  const offToAx = (q, r) => ({ q: q - (r + (r & 1)) / 2, r });
  const a = offToAx(q1, r1), b = offToAx(q2, r2);
  const dq = Math.abs(a.q - b.q), dr = Math.abs(a.r - b.r), ds = Math.abs(a.q + a.r - b.q - b.r);
  return Math.max(dq, dr, ds);
}
```

**算法拆解**：
1. `offToAx`：Even-R offset 转 axial（列移校正 `q - (r + (r&1))/2`）。
2. 取两 axial 的 `dq / dr / ds`（`ds = |q+r` 差，即立方 z 轴差）。
3. cube 距离 = `max(dq, dr, ds)`。

此函数被 `findPath` 的 A* 启发式直接复用（`heuristic = (a,b) => this.hexDistance(a.q,a.r,b.q,b.r)`）。

## 3. 前端坐标转换（已有，纯 2D 数学）

位置：`mecha-universe-engine/frontend/src/utils/hexUtils.js`

### 3.1 尖顶 Even-R 中心坐标
```js
export function pointyTopCenter(q, r, size, spacingH = 1, spacingV = 1) {
  let x = size * Math.sqrt(3) * q * spacingH
  if (r % 2 === 0) x += (size * Math.sqrt(3) / 2) * spacingH
  const y = size * 1.5 * r * spacingV
  return { flatX: x, flatY: y }
}
```

### 3.2 像素 → 六边形（逆推，含奇偶行修正）
```js
export function pointyTopToHex(flatX, flatY, size, spacingH = 1, spacingV = 1) {
  const x = flatX / spacingH
  const y = flatY / spacingV
  const rFrac = y / (1.5 * size)
  const r = Math.round(rFrac)
  const offset = (r % 2 === 0) ? (size * Math.sqrt(3) / 2) : 0
  const qFrac = (x - offset) / (size * Math.sqrt(3))
  const q = Math.round(qFrac)
  return { q, r }
}
```

### 3.3 像素/六边形互转统一入口
```js
export function hexToPixel(q, r, spacingH = 1, spacingV = 1, offsetFactor = 0) {
  const { flatX, flatY } = pointyTopCenter(q, r, HEX_RADIUS, spacingH, spacingV)
  return { x: flatX, y: flatY }
}
export function pixelToHex(px, py, spacingH = 1, spacingV = 1, offsetFactor = 0, ...)
  → 委托 pointyTopToHex(px, py, HEX_RADIUS, spacingH, spacingV)
```

## 5. 范围枚举（后端已支持）

位置：`services/map-service/src/utils/hexUtils.js:112`
```js
getHexesInRange(centerQ, centerR, range) {
  const results = [];
  for (let q = -range; q <= range; q++) {
    for (let r = Math.max(-range, -q - range); r <= Math.min(range, -q + range); r++) {
      results.push({ q: centerQ + q, r: centerR + r });
    }
  }
  return results;
}
```
此函数基于 axial/cube 范围环（满足 `|q|+|r|+|s| <= range` 的六边形范围），与 `hexDistance` 同源，可直接用于「射程可达格枚举」「辐射范围 aoe_radius 枚举」。

## 6. 方向判定（前端，与距离无关但依赖坐标差）

位置：`frontend/src/utils/hexUtils.js:664`
```js
export function computeDirection(fromQ, fromR, toQ, toR) {
  if (fromQ === toQ && fromR === toR) return null
  const dx = toQ - fromQ, dy = toR - fromR
  let angle = Math.atan2(dy, dx) * (180 / Math.PI)
  if (angle < 0) angle += 360
  const sector = Math.floor(((angle + 30) % 360) / 60)
  return sector + 1   // 1=正右 2=右下 3=左下 4=正左 5=左上 6=右上
}
```
采用 atan2 角度量化，**绝杀 Even-R 奇偶行 Delta 歧义**，不依赖固定 delta 硬匹配。
