## T2 第九章 详细检查项（⚠️ 落点已修正）

**前置确认**（已执行核查，**修正原假设**）：
- ❌ 原假设"在 damagePipe 接入"**错误**：技能伤害走 `skillExecutor._executeAttackSkill`（L363 `const baseDamage = uf.base_damage || uf.damage_modifier_precise || 0`），**不调用 `damagePipe.calculate`**（那是另一条独立路径）。
- `fixed_rate_multiplier` / `flat_value` 是 **effect 维度**字段（`src.effects[].fixed_rate_multiplier`），`normalizeSkill` 未提取到 `uf` 顶层。
- 正确落点：**`skillExecutor._executeAttackSkill`**，从 `uf.effects` 的 damage effect 读取倍率/固定值。

**实施步骤**（已优化为最终版）：
1. 在 `_executeAttackSkill` L363 处，将 `const baseDamage = uf.base_damage || uf.damage_modifier_precise || 0;` 替换为：
   ```cjs
   const dmgEffect = (uf.effects || []).find(
     e => e.type === 'damage' || e.fixed_rate_multiplier != null || e.flat_value != null
   );
   const frm = dmgEffect ? Number(dmgEffect.fixed_rate_multiplier) : NaN;
   const fixedMult = (Number.isFinite(frm) && frm > 0) ? frm : 1.0;
   const flat = dmgEffect ? (Number(dmgEffect.flat_value) || 0) : 0;
   // legacyBase 已含网关侧 getEquipmentAttackStat 注入的武器攻击力（combat.ts L1516）
   const legacyBase = Number(uf.base_damage) || Number(uf.damage_modifier_precise) || 0;
   const baseDamage = (dmgEffect && (Number.isFinite(frm) || flat !== 0))
     ? Math.max(0, Math.round(legacyBase * fixedMult + flat))
     : legacyBase;
   ```
2. 无需拆 `unit.equipment`（武器加成已由 `legacyBase` 携带），单点改动、纯增量、零回归。

**验收**：
- 配置 attack 词条 effect `fixed_rate_multiplier=1.5, flat_value=0` → 靶场基础伤害 +50%。
- 手持高阶武器施放 → 武器加成被 1.5× 放大。
- 未配置 effect 倍率的旧词条（如 config.json `fixed_rate_multiplier: null`）结算值不变。
