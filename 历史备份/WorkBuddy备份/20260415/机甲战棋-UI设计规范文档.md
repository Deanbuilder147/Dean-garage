# 机甲战棋 UI 设计规范文档

> 本文档用于指导设计工具生成一致的UI页面，确保所有页面遵循统一的设计语言。

---

## 一、项目概述

- **项目名称**: 机甲战棋 (Mecha Battle)
- **设计风格**: 暗色调军事科技风 (Dark Military Tech)
- **技术栈**: Vue 3 + CSS Variables + SVG Icons
- **字体**: Space Grotesk (标题), Space Mono (等宽/数据)

---

## 三、页面结构

### 3.1 页面列表

| 路由 | 页面名称 | 功能描述 |
|------|----------|----------|
| `/login` | 登录页 | 用户登录 |
| `/register` | 注册页 | 用户注册 + 阵营选择 |
| `/home` | 主页 | 功能导航卡片 |
| `/units` | 机甲库 | 棋子列表 + 创建/编辑 |
| `/battlefields` | 战场编辑器 | 六角格地图编辑 |
| `/battle/:id` | 战斗页 | PixiJS 战场渲染 |
| `/preparation/:roomId` | 整备室 | 阵营选择 + 棋子部署 |

## 五、UI组件规范

### 5.1 按钮 (Button)

```vue
<template>
  <button class="tactical-btn" variant="primary|secondary|tertiary|danger">
    按钮文字
  </button>
</template>
```

**变体**:

| 变体 | 样式 | 用途 |
|------|------|------|
| `primary` | 绿色渐变背景 | 主要操作 |
| `secondary` | 透明背景 + 边框 | 次要操作 |
| `tertiary` | 文字样式 | 辅助操作 |
| `danger` | 红色背景 | 危险操作 |

**尺寸**: `small` (8px 16px) | `medium` (12px 24px) | `large` (16px 32px)

### 5.2 图标 (Icon)

```vue
<template>
  <Icon name="sword" size="24" variant="primary" />
</template>
```

**可用图标**:
- 战斗: `sword`, `shield`, `attack`
- 导航: `home`, `arrowLeft`, `arrowRight`
- 功能: `palette`, `box`, `map`, `rocket`
- 阵营: `earth`, `moon`, `star`
- 状态: `check`, `close`, `add`, `delete`, `edit`

### 5.3 卡片 (Card)

```vue
<template>
  <Card variant="elevated" class="custom-card">
    卡片内容
  </Card>
</template>
```

### 5.4 标签 (Tag)

```vue
<template>
  <Tag variant="blue|green|purple|red" size="small">
    标签内容
  </Tag>
</template>
```

### 5.5 数值步进器 (Stepper)

```
[-]  [ 5 ]  [+]
     ▲
  点击加减
```

### 5.6 弹窗 (Modal)

```vue
<template>
  <div class="modal-overlay">
    <div class="modal">
      <h3>标题</h3>
      <p>内容</p>
      <div class="modal-actions">
        <Button>取消</Button>
        <Button variant="primary">确认</Button>
      </div>
    </div>
  </div>

```

## 六、样式规范

### 6.1 字体

```css
--font-space: 'Space Grotesk', 'Courier New', monospace;
--font-mono: 'Space Mono', 'Courier New', monospace;
```

**字号**:
- `--text-xs`: 11px
- `--text-sm`: 13px
- `--text-base`: 14px
- `--text-lg`: 16px
- `--text-xl`: 20px

### 6.2 间距

```css
--space-1: 4px
--space-2: 8px
--space-3: 12px
--space-4: 16px
--space-5: 20px
--space-6: 24px
```

### 6.3 圆角

> 所有元素使用 **0圆角** (军事风格)

```css
--radius-sm: 0px
--radius-md: 0px
--radius-lg: 0px
```

### 6.4 边框

> 使用 **色调层级边框** (伪元素渐变) 代替实线边框

```css
.element::before {
  content: '';
  position: absolute;
  inset: 0;
  border: 1px solid var(--surface-container-highest);
  pointer-events: none;
}
```

### 6.5 过渡

```css
--transition-fast: 150ms
--transition-normal: 250ms

/* 使用 steps() 实现像素风动画 */
transition: all 0.2s steps(4);
```

1. **CSS Variables 格式** - 直接生成变量代码
2. **组件规范** - 每个组件的结构和状态
3. **布局网格** - 响应式布局规则
4. **图标 SVG** - 使用内联 SVG
