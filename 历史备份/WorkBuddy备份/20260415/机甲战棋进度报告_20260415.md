## 五、关键游戏规则

### 棋子构成
```
┌─────────────────────────────────────────┐
│  主机体 (40点)  |  跟随 Royroy (25点)   │
│  - HP: 结构×10  |  - HP: 结构×3         │
│  - 技能槽: 3个  |  - 部署范围: 1-3格    │
│  - 左右手可装备 |  - 技能槽: 2个        │
└─────────────────────────────────────────┘
```

### 伤害公式
```
近战 = 攻击方格斗 + (攻击方机动 - 防御方机动) + 武器加成 - 防具 - 防御方防御
远程 = 攻击方射击 + (攻击方机动 - 防御方机动) + 武器加成 - 防具 - 防御方防御
```
