## 二、详细内容

### 1. 地图编辑器：新增「删除地图」功能
**需求**：在「新建地图」按钮旁增加删除入口。

- **后端**：复用 `backend-gateway/src/routes/maps.ts` 第 235 行已存在的
  `DELETE /api/map/battlefields/:id`（带鉴权），无需新增。
- **前端（`NewBattlefieldView.vue`）**：
  - 在「新建地图」按钮右侧新增「`[ 删除地图 ]`」按钮，危险样式 `.btn-danger`（红色）。
  - 新增 `deleteCurrentMap()`：
    1. 二次 `confirm` 确认（提示操作不可恢复）；
    2. 调用 `mapAPI.deleteBattlefield(battlefield.value.id)`；
    3. 成功后刷新地图列表 `fetchMapFileList()`，并将编辑器重置为新地图空白态（id 置空，保持可用）。
  - **可用性约束**：按钮 `:disabled` 绑定 `!battlefield.id` —— 仅当当前加载的地图已保存、拥有后端 id 时可删；对未保存的新建地图点击会提示「请先保存地图」（因 `saveMap` 走 `updateBattlefield(id,...)`，新建未保存地图无 id，符合既有约束）。
- **部署**：已随前端整体重建镜像并重启。

- 效果：三项并排显示，窄屏不再折行堆叠。

### 3. 词条库页面支持滚动
**需求**：词条库前端页面需可滚动。

- 根容器 `.page-container` 原本为 `h-full flex flex-col min-h-0` 但**无滚动**，长词条列表会被视口截断。
- 改动：根容器增加 `overflow-y-auto`，整页可纵向滚动（已有 `panel-body` 局部滚动保持不变，二者不冲突）。

### 4. 分步向导适配新内容（含修改方案与实施）
**检查结论**：
- 向导原使用旧字段模型：`target_filter` / `cast_range`（单值）/ `range_type` / `dice_type` + `success_line` / `base_damage` 等。
- 这些旧字段在 `commitWizardSkill` 中经 `hydrateSkill()` 已能**自动归一化为新形状**
  （`target_scope` / `cast_range{min,max}` / `skill_shape` / `dice` 等），因此向导与现有编辑表单**基本适配**。
- **唯一缺口**：旧向导只能产出「单骰 + 命中线」模型，**无法产出新的多分支 `has_dice` 模型**（掷骰后按点数命中不同分支），与编辑器区块三已有的多分支能力不对齐。

**修改方案（已实施）**：
1. `wizardForm` 增加 `has_dice: false` 与 `dice_branches: []` 两个字段（声明处与 `toggleWizard` 重置处均初始化）。
2. **步骤 4（状语 Adverbial）** 末尾增加：
   - 「启用多分支投骰 (has_dice)」开关；
   - 开关开启后展示动态分支编辑器：每个分支含「生效点数 points」（支持逗号分隔 `1,2,3` 与区间 `4-6`）+ 多个「效果」（action 下拉取自 `BRANCH_ACTIONS`、数值、可选状态 key），可增删分支与效果。
3. `commitWizardSkill` 在 `has_dice` 为真时，用 `parseWizardPoints()` 解析点数、按 effects 构建 `dice_branches`；为假时保持旧单骰模型（`has_dice:false`），**向后兼容**。
4. 新增辅助函数 `addWizardBranch()`、`parseWizardPoints()`，以及配套 `.wiz-branches / .wiz-branch / .wiz-effects / .wiz-x / .wiz-add` 样式。

### 5. 词条中枢首页：显示全部词条列表（非单条详情）
**需求**：首页应呈现目前已存在的所有词条列表，而非单条详情。

- 在「技能编辑面板」之前新增 **「词条中枢首页 · 全部词条」总览面板**：
  - 列出所有现有词条（KEY / 名称 / 分类徽章 / 投骰 `🎲 dN` 标记）；

- 为每个技能卡片增加锚点 `:id="'skill-card-' + key"`，新增 `scrollToSkill()` 函数与总览列表样式（`.overview-list / .overview-item / .ov-key / .ov-name / .ov-cat / .ov-dice`）。
