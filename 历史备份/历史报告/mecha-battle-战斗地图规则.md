## 📋 地图概述

战斗地图是机甲战棋游戏的核心战斗场景，采用六边形网格系统，支持地形效果、单位部署和战术移动。

## 🗺️ 地图规格

### 默认尺寸
| 规格 | 值 |
|------|-----|
| **宽度** | 30 格 (列) |
| **高度** | 20 格 (行) |
| **总格数** | 600 格 |
| **网格类型** | 六边形 (Hexagonal) |

### 可选尺寸
| 尺寸 | 格数 | 适用场景 |
|------|------|----------|
| 小型 (15x10) | 150 格 | 快速对战/测试 |
| 中型 (20x15) | 300 格 | 标准对战 |
| 大型 (30x20) | 600 格 | 正式比赛 |
| 超大 (100x100) | 1200 格 | 大规模混战 |

## 🔷 六边形网格系统

### 坐标系统
采用 **轴向坐标 (Axial Coordinates)**：
- **q**: 列坐标 (横向)
- **r**: 行坐标 (斜向)
- **s**: 冗余坐标 (s = -q-r, 用于计算)

```
坐标示例：(q=5, r=3)
```

### 相邻格计算
六边形有 6 个相邻格，方向向量为：
```javascript
const HEX_DIRECTIONS = [
  { dq: +1, dr:  0 }, // 东
  { dq: +1, dr: -1 }, // 东北
  { dq:  0, dr: -1 }, // 西北
  { dq: -1, dr:  0 }, // 西
  { dq: -1, dr: +1 }, // 西南
  { dq:  0, dr: +1 }, // 东南
]
```

### 距离计算
```javascript
function hexDistance(a, b) {
  return (Math.abs(a.q - b.q) + 
          Math.abs(a.r - b.r) + 
          Math.abs(a.s - b.s)) / 2;
}
```

## 📍 部署规则

### 部署阶段
- **时机**: 游戏开始前 (第 0 回合)
- **顺序**: 按阵营→座位顺序依次部署
- **位置**: 地图任意空格

### 部署流程
```
1. 玩家点击地图格子
   ↓
2. 弹出确认对话框
   ↓
3. 确认部署
   ↓
4. 单位出现在地图
   ↓
5. 玩家开始行动流程
   ↓
6. 下一位玩家部署
```

### 部署限制
| 限制 | 说明 |
|------|------|
| **空格限制** | 只能部署在空格子上 |
| **障碍限制** | 不能部署在障碍物上 |
| **基地限制** | 不能部署在敌方基地上 |

## 🚶 移动规则

### 机动值
- **定义**: 每回合最大可移动格数
- **计算**: 机动属性值 = 移动格数
- **示例**: 机动 8 = 最多移动 8 格

### 移动路径
- **路径规划**: 可自由规划移动路径

### 移动限制
| 限制 | 说明 |
|------|------|
| **地形消耗** | 防御圈消耗5点（攻击距离也需要计算），基地/母舰内每次只能移动1 |
| **单位阻挡** | 不能穿越其他单位 |


### 移动行动
```
每回合可执行一次移动行动：
1. 选择己方单位
2. 显示移动范围
3. 点击目标位置
4. 确认移动
5. 单位移动到新位置
```
