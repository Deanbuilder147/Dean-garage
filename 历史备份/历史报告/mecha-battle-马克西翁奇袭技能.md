# 马克西翁军奇袭技能规则

**文档版本**: v1.0  
**最后更新**: 2026-04-07  
**所属阵营**: 马克西翁 (Maxion)  
**所属项目**: 机甲战棋游戏

---

## 📋 技能概述

**奇袭** (Surprise Attack) 是马克西翁阵营的专属技能，允许在敌方发动攻击时介入战斗，打乱敌方进攻节奏。

---

## 🎯 技能定义

| 属性 | 值 |
|------|-----|
| **技能名称** | 奇袭 (Surprise Attack) |
| **所属阵营** | 马克西翁 (Maxion) |
| **技能类型** | 被动触发/主动选择 |
| **阵营特性** | ['奇袭', '隐匿'] |

---

## ⏱️ 触发时机

### 时序图
```
回合开始 → 移动阶段 → 战术行动阶段
                      ↓
              声明战术子阶段 (玩家 A 选择攻击)
                      ↓
              选定目标子阶段 (确认攻击者→目标)
                      ↓
              【奇袭触发点】⚡
                      ↓
              询问马克西翁玩家是否发动奇袭
                      ↓
              执行奇袭 (如果有玩家选择发动)
                      ↓
              继续原攻击流程
```

---

## ✅ 发动条件

### 必要条件
| 条件 | 说明 |
|------|------|
| **阵营限制** | 只有马克西翁阵营单位可发动 |
| **射程要求** | 奇袭单位必须在攻击范围内 |
| **状态要求** | 单位 HP > 0 且未跳过下回合 |
| **次数限制** | 每次攻击最多触发一次奇袭 |

### 攻击范围判定
```
奇袭单位可以：
- 攻击原攻击者
- 攻击原目标
- 两者都在范围内 → 可选择顶替或先制
- 只有其一在范围内 → 只能先制攻击
```

---

## 🎲 奇袭选项

### 选项对比

| 选项 | 条件 | 效果 | 适用场景 |
|------|------|------|----------|
| **⚔️ 顶替攻击** (Replace) | 原攻击者 + 原目标 都在范围内 | 奇袭单位攻击原攻击者，原攻击被取消 | 消灭高威胁攻击单位 |
| **🛡️ 先制攻击** (Counter) | 至少一个目标在范围内 | 奇袭单位优先攻击，原攻击继续进行 | 保护己方脆弱单位 |
| **❌ 放弃** | 任意情况 | 不发动奇袭，原攻击正常进行 | 保存实力/等待更好时机 |

### 选择逻辑
```
如果 原攻击者 AND 原目标 都在范围内:
    → 可选择【顶替攻击】或【先制攻击】
否则如果 原攻击者 OR 原目标 在范围内:
    → 只能选择【先制攻击】
否则:
    → 无法发动奇袭
```

---

## 👥 多人奇袭处理

### 场景
当多个马克西翁单位同时满足奇袭条件时：

### 处理流程
```
1. 系统检测所有可奇袭的马克西翁单位
   ↓
2. 向所有候选单位玩家显示奇袭弹窗
   ↓
3. 启动 10 秒倒计时
   ↓
4. 收集所有玩家选择
   ↓
5. 如果多个单位选择发动:
   - 掷骰子决定优先级 (d6)
   - 点数最高的单位执行奇袭
   ↓
6. 执行奇袭并结算
```

### 掷点规则
| 规则 | 说明 |
|------|------|
| **骰子类型** | d6 (六面骰) |
| **平局处理** | 平局则重新掷点 |
| **超时处理** | 10 秒内未选择视为放弃 |

## 💰 代价与限制

### 代价
| 项目 | 说明 |
|------|------|
| **跳过下回合** | 发动奇袭的单位失去下一次行动机会 |
| **状态标记** | `surpriseUsedThisAttack = true` |

### 限制
| 限制 | 说明 |
|------|------|
| **次数限制** | 每次攻击最多一次奇袭 |
| **阵营限制** | 只有马克西翁阵营可发动 |
| **射程限制** | 必须在攻击范围内 |
| **状态限制** | HP ≤ 0 或已跳过下回合的单位无法发动 |

### 优先级顺序
```
指定目标 → 奇袭 → 长柄 → 扫射 → 投掷 → 援助
```

## 💡 战术价值

### 优势
| 优势 | 说明 |
|------|------|
| ✅ 打乱节奏 | 打乱敌方进攻计划和节奏 |
| ✅ 消灭威胁 | 消灭高威胁攻击单位 |
| ✅ 保护友军 | 保护己方脆弱单位 |
| ✅ 心理威慑 | 敌方不敢轻易进攻 |
| ✅ 战术灵活 | 可选择顶替或先制 |

### 劣势
| 劣势 | 说明 |
|------|------|
| ❌ 失去行动 | 跳过下回合，失去行动机会 |
| ❌ 暴露位置 | 发动奇袭暴露自身位置 |
| ❌ 可能浪费 | 可能浪费在低价值目标上 |
| ❌ 依赖射程 | 需要单位在攻击范围内 |

### 使用时机
| 时机 | 建议 |
|------|------|
| 敌方高威胁单位攻击 | ✅ 推荐发动，消除威胁 |
| 敌方攻击己方脆弱单位 | ✅ 推荐发动，保护友军 |
| 己方单位下回合不重要 | ✅ 可发动，代价较小 |
| 敌方攻击低价值目标 | ❌ 建议放弃，保存实力 |
| 奇袭单位下回合关键 | ❌ 建议放弃，避免损失 |

## 🔧 技术实现

### 核心代码位置
| 文件 | 功能 |
|------|------|
| `/game/core/TurnManager.js` | 回合管理、奇袭触发时机 |
| `/game/core/CombatResolver.js` | 战斗结算、奇袭执行 |
| `/game/core/SurpriseAttackManager.js` | 奇袭逻辑核心 |
| `/game/ui/SurpriseDialog.vue` | 奇袭弹窗 UI |

### 关键函数
```javascript
// 检查是否可发动奇袭
function canSurpriseAttack(unit, attacker, target) {
  return unit.faction === '马克西翁' &&
         unit.hp > 0 &&
         !unit.skipNextTurn &&
         isInRange(unit, attacker) || isInRange(unit, target);
}

// 执行奇袭
function executeSurpriseAttack(surpriseUnit, target, type) {
  surpriseUnit.skipNextTurn = true;
  resolveCombat(surpriseUnit, target);
  if (type === 'replace') {
    cancelOriginalAttack();
  }
}
```

## 📊 实战示例

### 场景 1: 顶替攻击
```
局势:
- 玩家 1(拜隆) 的【重装机兵】攻击 玩家 2(地球联合) 的【狙击吉姆】
- 玩家 3(马克西翁) 的【影刃】在【重装机兵】和【狙击吉姆】的攻击范围内

选择: 顶替攻击
结果:
- 【影刃】攻击【重装机兵】
- 原攻击 (重装机兵→狙击吉姆) 被取消
- 【影刃】跳过下回合
```

### 场景 2: 先制攻击
```
局势:
- 玩家 1(拜隆) 的【重装机兵】攻击 玩家 2(地球联合) 的【狙击吉姆】
- 玩家 3(马克西翁) 的【幽灵】只在【狙击吉姆】的攻击范围内

选择: 先制攻击
结果:
- 【幽灵】优先攻击【狙击吉姆】
- 原攻击 (重装机兵→狙击吉姆) 继续进行
- 【幽灵】跳过下回合
```

### 场景 3: 多人奇袭
```
局势:
- 玩家 1(拜隆) 攻击 玩家 2(地球联合)
- 玩家 3(马克西翁) 的【影刃】和 玩家 5(马克西翁) 的【幽灵】都可奇袭

处理:
- 两玩家都选择发动奇袭
- 掷点：影刃🎲4 vs 幽灵🎲6
- 【幽灵】胜出，执行奇袭
- 【影刃】失去奇袭机会
```
