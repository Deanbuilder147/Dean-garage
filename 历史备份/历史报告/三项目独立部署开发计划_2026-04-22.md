## 一、项目愿景

将现有的单体机甲战棋游戏拆分为三个独立项目，通过 JSON 文件进行数据交换，实现：
- 各系统独立部署、独立开发
- 数据标准化、可离线运行
- 便于测试和扩展

| 方法 | 路径 | 说明 |
|------|------|------|

#### 数据模型

```typescript
interface Unit {
  id: number;
  name: string;                    // 名称: "铁拳"
  faction: string;                  // 阵营: "earth" | "mars" | "maxion"
  main_type: string;                // 主类型: "格斗" | "射击" | "支援"

  // 核心属性
  格斗: number;                     // 0-20
  射击: number;
  结构: number;
  机动: number;

  // 装备槽位
  left_hand: Equipment | null;
  right_hand: Equipment | null;
  extra_1: Equipment | null;
  extra_2: Equipment | null;
  extra_3: Equipment | null;

  // 元数据
  hp: number;                       // 默认 10
  created_at: string;
  updated_at: string;
}

interface Equipment {
  type: "weapon" | "armor" | "engine" | null;
  name: string;
  格斗?: number;
  射击?: number;
  机动?: number;
  durability?: number;
}
```

```typescript
interface Battlefield {
  id: number;
  name: string;                    // "标准战场"
  width: number;                   // 20 (格子数)
  height: number;                  // 15
  type: string;                    // "standard" | "siege" | "capture"

  // 地形数据 (六角格坐标)
  terrain: {
    [coordinate: string]: TerrainType;
  };

  // 阵营出生点
  spawns: {
    [faction: string]: { x: number; y: number };
  };

  // 元数据
  created_at: string;
  updated_at: string;
}

type TerrainType =
  | "plain"      // 平原
  | "mountain"   // 山地
  | "river"      // 河流
  | "forest"     // 森林
  | "mothership" // 母舰
  | "obstacle";  // 障碍物
```

### 3.3 mecha-combat (战斗系统)

#### 端口
```
3003
```

#### API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/combat/start | 开始新战斗 |
| POST | /api/combat/:id/action | 执行动作 |
| GET | /api/combat/:id | 获取战斗状态 |
| GET | /api/combat/:id/log | 获取战斗日志 |
| GET | /api/results | 获取历史战斗记录 |

#### 战斗流程

```
1. 加载数据
   └─> 读取 units.json + battlefields.json

2. 初始化战斗
   └─> 读取 battlefields[id]
   └─> 读取 units[selected_ids]
   └─> 部署单位到出生点

3. 回合循环
   └─> 每回合: 玩家操作 → 骰子判定 → 结算 → 保存

4. 结束战斗
   └─> 判定胜负
   └─> 生成 battle_result.json
   └─> 返回结果给前端
```

#### 骰子系统 (CombatResolver)

```typescript
class CombatResolver {
  // 基础掷骰
  static rollDice(sides: number = 6): number;

  // 攻击判定
  static resolveAttack(
    attacker: Unit,
    target: Unit,
    attackType: "melee" | "ranged"
  ): AttackResult;

  // 斩杀判定
  static executeCheck(targetHp: number): boolean;

  // 格挡判定
  static blockCheck(hasArmor: boolean): BlockResult;

  // 奇袭判定 (马克西翁专属)
  static surpriseCheck(attacker: Unit): SurpriseResult;
}
```

#### 判定规则

| 判定类型 | 骰子 | 条件 | 效果 |
|---------|------|------|------|
| 攻击 | - | 自动命中 | 伤害 = 攻击属性 + 武器加成 - 防御 |
| 斩杀 | d6 | HP < 5 且近战 | 掷骰 ≥ 剩余HP → 击杀 |
| 格挡 | d6 | 有防具 | 掷骰 > 3 → 减伤2 |
| 抢夺 | d6 | 造成伤害 > 武器攻击 | 掷骰 ≥ 4 → 抢夺成功 |
| 专注射击 | d6 | 远程攻击 | ≥5 → 伤害+5, ≥1 → 伤害+3 |
| 奇袭 | d10 | 马克西翁阵营 | 黑(≤5) → 伤害+2, 红(>5) → 移动-1 |

#### 输出 JSON

```json
// data/results/battle_20260422_001.json
{
```

## 十、附录

### A. 六角格坐标系统

```
使用轴坐标 (Axial Coordinates)
- q: 列 (x方向)
- r: 行 (y方向)
- 原点 (0,0) 在左上角

转换公式:
  像素x = size * (3/2 * q)
  像素y = size * (sqrt(3)/2 * q + sqrt(3) * r)
```
