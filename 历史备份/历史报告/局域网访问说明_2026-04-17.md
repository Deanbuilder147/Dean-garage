## 常见问题排查

### ❌ 问题 1: 无法访问/连接超时

**检查步骤**:

1. **确认在同一网络**
   ```bash
   # 在其他机器上查看 IP
   ipconfig  # Windows
   ifconfig  # Mac/Linux
   ```
   确保 IP 地址前缀相同 (如都是 `10.0.0.x`)

2. **Ping 测试**
   ```bash
   ping 10.0.0.9
   ```
   如果不通，检查网络连接

3. **端口测试**
   ```bash
   telnet 10.0.0.9 5173
   # 或
   nc -zv 10.0.0.9 5173
   ```

4. **检查防火墙**
   ```bash
   # 在服务器上执行
   sudo ufw status | grep 5173
   ```

### ❌ 问题 2: 页面加载但资源错误

**原因**: Vite 开发服务器的 HMR (热模块替换) 配置问题

**解决**: 
- 直接刷新页面 (Ctrl+F5 / Cmd+Shift+R)
- 或访问时加上完整路径

### ❌ 问题 3: 只能访问一个应用

**检查**:
```bash
# 确认两个端口都在监听
netstat -tlnp | grep -E "5173|5174"
```

**解决**: 重启服务
```bash
pkill -f "vite"
cd /home/agentuser/Dean-garage/apps/chess-system && npm run dev &
cd /home/agentuser/Dean-garage/apps/battle-map && npm run dev &
```

