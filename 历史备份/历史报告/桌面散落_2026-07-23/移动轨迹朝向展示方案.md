## 一、现状（已经做了什么）

棋子的"朝向 / 动作状态"已经有一套可工作的机制，核心三件套：

| 机制 | 位置 | 作用 |
|------|------|------|
| `getUnitVisual(unit)` | `NewBattleView.vue` | 返回 `{ direction, actionState }`，从 `unitSpriteState`（以 unitId 为 key 的 Map）读取 |
| `setUnitVisual(unitId, direction, actionState)` | `NewBattleView.vue` | 写入朝向与动作状态 |
| `unitSpriteResolver.getTexture(unitCode, direction, actionState)` | `frontend/src/resolvers/unitSpriteResolver.js` | 按 `direction(0-6)` + `actionState` 选 7 视图 PNG，4 级降级链 |

**方向语义**（7 视图，`unitSpriteResolver.js` 头部注释明确）：
- `direction = 0`：正面特写（Front / Idle）
- `direction = 1~6`：六角格六方向（由 `computeDirection` 量化得出）

**当前移动时的朝向处理**（`executeMove`，约 2300 行）：
```js
const dir = computeDirection(fromQ, fromR, tq, tr)   // 算出 from→to 的 1~6 方向
if (dir !== null) setUnitVisual(unitId, dir, 'move')  // 设朝向 + 移动态
// ... 直直 lerp 从 from 到 to ...
// lerp 完成后 refreshState + setUnitVisual(unitId, dir ?? 0, 'idle')
```
`computeDirection`（hexUtils.js）：用 `atan2(dy, dx)` 把屏幕坐标差量化到 6 扇区（每扇区 60°），返回 `1~6`，同格返回 `null`。已规避 Even-R 奇偶行判定死锁。

**关键缺口**：后端 `moveUnit`（`battleState.js` / `battles.js` 路由）只做 BFS **可达性校验**，返回结果里**没有路径数组**。前端因此只能"直线 lerp from→to"，朝向也只取**整段净方向**，不会跟随多格路径的转弯。

---

## 二、目标

让棋子在沿路径移动时：
1. 真的沿后端算出的**路径逐格行走**（而非直线飞过去）；
2. **每一段**都按该段方向更新朝向（转弯时棋子转向对应方向）；
3. 到达终点后保留最后的移动朝向（或按规则回落到 idle 正面 0）。

---

## 三、需要做的改动（清单）

### A. 后端：移动接口返回路径数组
- 文件：`services/combat-service/src/state/battleState.js` 的 `moveUnit`（内部已有 `canMoveTo` BFS），重构 BFS 使其在判定可达的同时**记录前驱、回溯出完整路径**（`[{q,r}, ...]` 从起点到终点）。
- 文件：`services/combat-service/src/routes/battles.js` 的 `move` 路由，把 `path` 放入返回 JSON（如 `result.path`）。
- 网关桥接 `backend-gateway/src/combatBridge.ts` 透传即可（确认移动 action 返回值未被裁剪）。

### B. 前端：按路径逐段行走 + 逐段设朝向
- 文件：`NewBattleView.vue` 的 `executeMove`：
  1. 读取后端返回的 `path` 数组；
  2. 若没有 path（兼容旧接口），保留当前"直线 + 净方向"行为作为兜底；
  3. 若有 path，改为**段循环**：对 `path[i] → path[i+1]` 每相邻两格：
     - `segDir = computeDirection(path[i].q, path[i].r, path[i+1].q, path[i+1].r)`
     - `setUnitVisual(unitId, segDir, 'move')`
     - `startLerpAnimation(unitId, 格 i, 格 i+1, perSegDuration, ...)`
  4. 全部段走完后：`setUnitVisual(unitId, lastSegDir ?? 0, 'idle')`（或按你偏好：保留 lastSegDir / 回落 0）。

### C. 资源：确认 7 视图素材齐全
- `unitSpriteResolver.preload` 已预加载 `direction 0~6` × `idle/move/attack/damaged` 全部切片。
- 需确认实际美术资源对每个机体都有 `_{1..6}_move` 帧；缺则走降级链（→ `_idle` → `_0_idle` → `DEFAULT`），不会崩，但转弯表现会退化。
