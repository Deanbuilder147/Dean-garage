- [ ] 任务 4.1：实装“隐匿 (Stealth)”机制与 UI 表现

  Agent 执行动作：前后端联动实现隐身逻辑。

  关键补漏（机制细节与表现）：

- [ ] 任务 4.2：实装“奇袭 (Surprise Attack)”机制与 UI 表现

  Agent 执行动作：编写基于隐匿状态的截击算法与特效。

  关键补漏（机制细节与表现）：

  机制规则：

  预支（伏击设定）：处于“隐匿”状态的机体，可以在操作底栏点击“奇袭设定”，预支剩余 AP，划定周围 N 格范围作为 overwatch\_zone（警戒区），提交给后端。

  触发（强制打断）：当敌方玩家执行移动指令，且路径坐标穿过该 overwatch\_zone 时，后端网关直接打断敌方移动。

  破隐：无论是否击中，伏击方强制解除 stealth 状态，暴露坐标。

  奇袭触发瞬间，全场（含观众和敌方）游戏画面强制暂停。

  屏幕中央闪烁高对比度的警告 UI（类似赛博朋克风的 "WARNING: SURPRISE ATTACK DETECTED" 红色荧光字样）。

  伏击机甲瞬间显形，并播放强制先制攻击的特效。
