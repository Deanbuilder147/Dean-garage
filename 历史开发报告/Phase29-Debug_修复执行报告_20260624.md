## 工序三：Nginx 全量纠偏

### CSP 熔断解除
```nginx
# 旧
script-src 'self';
# 新
script-src 'self' 'unsafe-eval';
```
Vue 动态编译模板不再被 CSP 拦截白屏。

### 尾斜杠 301 根除
```nginx
# 旧
location /api/units/ {
# 新
location /api/units {
```
无尾斜杠请求 `/api/units` 不再落入 SPA fallback。

### 缓存分层
| Location | Cache-Control | 说明 |
|---|---|---|
| `/assets/` | `max-age=31536000, immutable` | hash 指纹资产长期缓存 |
| `/` | `no-cache, no-store` | SPA 入口不缓存 |

### CSP 回填修复
- Nginx `add_header` 不继承：子 location 有任何 `add_header` 即抹除父级安全头
- 修复: `location /` 显式注入全套安全头（CSP + HSTS + Referrer + X-Content-Type + X-Frame）

### 新增路由
```nginx
# 词条库独立路由
location /api/combat-glossary/ {
    proxy_pass http://mecha-gateway:3006;
}
```
