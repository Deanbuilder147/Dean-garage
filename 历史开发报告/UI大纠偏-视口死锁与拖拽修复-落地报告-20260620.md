## 一、病灶诊断

| # | 文件 | 选择器 | 病根 | 症状 |
|---|------|--------|------|------|
| ① | `NewBattlefieldView.vue` | `.main-content` | `min-height:100vh` 可撑爆，未启 flex 列排布 | Canvas 撑大容器 → 3D 视角滑块 + 间距控件沉底不可见 |

| ③ | `NewBattleView.vue` | `.dm-action-panel` | 缺 `flex-shrink:0` | 右侧行动栏被主区域撑宽后挤出屏幕右侧 |

## 二、精确修复清单

### 修复 ①: NewBattlefieldView.vue

```css
/* BEFORE — 漏洞：可无限撑高，无 flex 列约束 */
.page-container { /* 空或不存在 */ }
.main-content {
  min-height: 100vh;    /* ❌ 允许 >100vh */
  min-width: 0;
  width: 100%;
  overflow: hidden;
  /* ❌ 缺 display:flex; flex-direction:column; */
}

/* AFTER — 锁死视口 + flex 列排布 */
.page-container {
  height: 100vh;         /* ✅ 硬锁定 */
  overflow: hidden;      /* ✅ 禁止滚动条 */
  display: flex;         /* ✅ flex 容器 */
  flex-direction: column;/* ✅ 垂直排布 */
}
.main-content {
  height: 100vh;         /* ✅ 替换 min-height */
  overflow: hidden;
  display: flex;         /* ✅ flex 容器 */
  flex-direction: column;/* ✅ 子元素列排布 */
  min-width: 0;
  width: 100%;
}
```

### 修复 ②: HexGridCanvas.vue

```css
/* BEFORE */

  position: relative;
  overflow: hidden;
  flex: 1;

}
```
