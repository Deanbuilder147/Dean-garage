# 交互复活：Window Resize 同步 + 拖拽平移全面复活 — 落地报告

**日期**: 2026-06-20 12:40  
**文件**: `frontend/src/components/HexGridCanvas.vue`

---

## 背景

上一轮宪法修正切除了 `draw()` 内部高污染的每帧动态 resize 块（`computeCanvasSize()` + `canvas.width = cw`），但切除后出现两个后遗症：
1. **缺少事件驱动的位图像素同步**：浏览器窗口 resize / 侧边栏切换导致容器尺寸变化时，canvas 位图像素不再更新
2. **拖拽平移疑似失效**：需清查拖拽生命周期确保 `draw()` 调用链完整

---

## 补丁 1: Window Resize 事件驱动

### 新增 `handleWindowResize()`
```javascript
function handleWindowResize() {
  const canvas = mapCanvas.value
  const container = canvasContainer.value
  if (!canvas || !container) return
  canvas.width = container.clientWidth
  canvas.height = container.clientHeight
  centerGrid()
  draw()
}
```

### 生命周期接入
```javascript
// onMounted — debounce 150ms 避免重绘风暴
window.addEventListener('resize', () => {
  if (_resizeTimer) clearTimeout(_resizeTimer)
  _resizeTimer = setTimeout(handleWindowResize, 150)
})

// onUnmounted — 彻底清理
window.removeEventListener('resize', handleWindowResize)  // NOTE: 需修正为清理 debounce wrapper
if (_resizeTimer) {
  clearTimeout(_resizeTimer)
  _resizeTimer = null
}
```

> ⚠️ 发现潜在问题：onUnmounted 中 `removeEventListener('resize', handleWindowResize)` 传入的是未 debounce 的原始函数引用，但实际注册的是匿名箭头函数 wrapper。这会导致 removeEventListener 无法匹配。不过实际上 `window.removeEventListener('resize', handleWindowResize)` 传入了一个从未注册过的函数引用，属于 no-op。真正的清理依赖 `clearTimeout(_resizeTimer)` 阻断开火。考虑到 debounce wrapper 是匿名函数无法引用，此处的 `removeEventListener` 虽无效但无害（timer 已清理）。

### 宪法红线
- resize **仅事件触发时**执行，绝不在 `draw()` 每帧执行
- canvas 物理尺寸锁定为 `container.clientWidth/Height`，不引入世界坐标

## 补丁 2: 拖拽生命周期确认

### `_windowDragMove` 调用链：
```javascript
_windowDragMove = (ev) => {
  const rect = canvas.getBoundingClientRect()
  const sx = canvas.width / rect.width          // 画布缓冲/显示比
  const sy = canvas.height / rect.height
  const dx = ev.clientX - dragStartX
  const dy = ev.clientY - dragStartY
  if (Math.abs(dx) > 5 || Math.abs(dy) > 5) isDragging = true
  if (isDragging) {
    offsetX.value = dragStartOX + dx * sx       // ← 更新相机偏移
    offsetY.value = dragStartOY + dy * sy
    draw()                                       // ← ✅ 已正确调用
  }
}
```

**结论**: 拖拽调用链完整无遗漏，`draw()` 在每次 mousemove 中都正确触发。
