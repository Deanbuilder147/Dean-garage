### 2.2 skillExecutor.cjs — 8 技能逐个重写（14,259 字节）

| 技能 | 原逻辑（骰子） | 新逻辑（确定性） | 文件位置 |
|------|--------------|----------------|---------|
| **格挡** block | `1d6 >= 4 → 伤害-2` | **100% 触发，伤害-2** | `executeBlock()` |
| **扫射** sweep | `1d6 ≤ 3 → 精准单体, 4-6 → 范围均摊` | **确定性精准命中单体** | `executeSweep()` |
| **投掷** throw | `1d6 ≤ 3 → +5伤害, 4-6 → 机动减半` | **确定性目标+5伤害增益** | `executeThrow()` |
| **斩杀** execute | `HP < 5 且 1d6 ≥ HP → 斩杀` | **HP < 10% maxHP → 直接斩杀** | `executeExecute()` |
| **决斗** duel | `双方各掷1d6比大小 → 大者胜` | **比较 max(格斗,射击) → 高者胜** | `executeDuel()` |
| **抢夺** snatch | `伤害 > 武器攻击 且 1d6 > 3 → 抢夺` | **伤害 > 武器攻击 → 100%抢夺** | `executeSnatch()` |
| **专注射击** focused_fire | `1d6 ≤ 4 → +3, 5-6 → +5` | **固定 +4** | `executeFocusedFire()` |
| **幸运** lucky | `1d6: 1-2 skip / 3-4 attack / 5-6 move+attack` | **始终获得再移动攻击** | `executeLucky()` |

**关键变更**：
- 构造函数从 `constructor(dice)` 改为 `constructor()`，不再接受 DiceEngine 参数
- 新增词条库配置加载：`require('../../config/glossary-skill-config.json')`
- 每个技能都先尝试从 JSON 配置读取参数，失败则使用硬编码默认值

### 2.5 unitConverter.js — 描述文本去骰化

`_getSkillDesc()` 方法中 8 个技能描述全部替换：
- `掷骰1-3失败/4-6伤害-2` → `伤害-2`
- `掷骰1-3精准命中单体-2，4-6范围均摊` → `精准命中单体造成伤害-2，范围攻击伤害由所有目标均摊`
- `掷骰1-3目标周围2格下次伤害+5，4-6目标移动值-5` → `目标周围2格所有目标下次伤害+5`
- `目标HP<5时掷骰，点数≥剩余血量→直接斩杀` → `目标HP<10%最大HP时直接斩杀`
- `双方掷骰大者胜` → `攻击力高者胜`
- `掷骰，点数>3→伤害减半并获得武器` → `伤害值>被攻击者武器攻击值时触发，伤害减半并获得武器`
- `掷骰：1-4伤害+3，5-6伤害+5` → `获得固定伤害加成+4`
- `获得空投时掷骰：1-2跳过攻击，3-4可攻击，5-6再移动攻击` → `获得空投时可再次移动并攻击`
