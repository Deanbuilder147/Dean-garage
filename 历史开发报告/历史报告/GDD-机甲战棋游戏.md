## 一、游戏是什么？

**一句话描述**：一款可以在浏览器里玩的回合制战棋游戏，玩家上传机甲图片作为棋子，在六角形战场上布阵对战。

**核心体验**：
- 参考超级机器人大战（GBA版）的视觉风格
- 玩家自己上传机体图片 → 系统显示为棋子
- 两个人（或人机）轮流操控机甲，在六角形地图上移动、攻击
- 伤害计算、回合流程全部自动处理

## 三、游戏规则（来自战斗系统2.0alpha）

### 3.1 棋子结构（角色卡）

每个棋子由5个部件组成：

```
┌─────────────────────────────────────────┐
│              完整棋子（Unit）            │
├──────────┬──────────────────────────────┤
│  主机体   │  必须（机体类型，40点）       │
│  - HP    │  结构 × 10                   │
│  - 技能  │  3个槽                        │
├──────────┼──────────────────────────────┤
│  跟随    │  可选（Royroy类型，25点）      │
│  - HP    │  结构 × 3                     │
│  - 部署  │  主机体周围1-3格，跟随移动      │
│  - 技能  │  2个槽                        │
├──────────┼──────────┬───────────────────┤
│  左手    │  右手     │  其它             │
│ （可选）  │ （可选）   │  背包 或 载具    │
│武器/防具  │武器/防具  │  （可选）        │
│ 各15点   │ 各15点    │  各15点          │
└──────────┴──────────┴───────────────────┘
```

**部件属性说明**：
- 武器：攻击时提供额外攻击加成
- 防具：抵消3点伤害（耐久5次，归0消失）
- 背包：提供HP加成（耐久5，归0加成消失）
- 载具：增加移动范围，被攻击时机动+4

### 3.2 属性系统

| 属性 | 作用 |
|------|------|
| **格斗** | 近战攻击伤害基础值 |
| **射击** | 远程攻击伤害基础值 |
| **结构** | 用于计算HP（机体×10，Royroy×3） |
| **机动** | 移动距离 + 影响命中回避 |

### 3.3 伤害计算公式

```
近战伤害 = 攻击方格斗 + (攻击方机动 - 防御方机动) + 武器加成 - 防具抵消 - 防御方防御
远程伤害 = 攻击方射击 + (攻击方机动 - 防御方机动) + 武器加成 - 防具抵消 - 防御方防御
```

**示例**：
- 攻击方格斗=15，机动=12
- 防御方机动=10，防御力=5，防具抵消=3
- 近战伤害 = 15 + (12-10) + 0 - 3 - 5 = **9点**

### 3.4 回合流程

```
┌─────────────────────────────────────────────────────────┐
│                    回合开始阶段                          │
│  1. 检查Royroy部署状态                                  │
│     - 未部署：玩家需选择1-3格内位置部署                  │
│  2. 月面地形回复（拜隆阵营）                            │
│     - 处于月面的拜隆单位回复4点HP                        │
│  3. 检查单位HP，归零者移除                              │
├─────────────────────────────────────────────────────────┤
│                    战术行动阶段                          │
│  每回合每个单位可执行：                                  │
│  1. 移动行动（可跳过）                                  │
│     - 移动距离 = 机动值 + 载具加成                       │
│     - 可穿越友军，不可穿越敌军                           │
│  2. 攻击行动（可跳过）                                  │
│     - 近战：周围一圈                                     │
│     - 远程：指定距离内                                   │
│     - 使用武器/防具消耗战术行动                          │
├─────────────────────────────────────────────────────────┤
│                    回合结束阶段                          │
│  1. 结算所有状态效果                                    │
│  2. 切换到下一玩家                                       │
└─────────────────────────────────────────────────────────┘
```

### 3.5 Royroy特殊规则

| 项目 | 规则 |
|------|------|
| **部署时机** | 每回合开始时必须部署或确认位置 |
| **部署位置** | 主机体周围1-3格内 |
| **跟随移动** | 随主机体移动，可重新选择跟随位置 |
| **攻击** | 可被指定为攻击/防御目标 |
| **HP计算** | 结构 × 3 |

### 3.6 马克西翁奇袭规则

**触发条件**：马克西翁单位可以在敌方攻击时选择发动

**效果选择**（二选一）：

| 选项 | 效果 |
|------|------|
| **顶替攻击** | 用自己的攻击顶替原攻击方的攻击（需攻击范围覆盖目标） |
| **先制攻击** | 先于原攻击方发动攻击，然后掷骰 |

**掷骰效果**：
| 骰点 | 效果 |
|------|------|
| 黑(2/3/5/6) | 本次攻击伤害 + 骰点值/2（向上取整） |
| 红(1/4) | 下次可移动距离减少骰点值 |

**代价**：跳过自己的下个回合

### 3.7 阵营系统

| 阵营 | 特性 | 效果 |
|------|------|------|
| **地球联合** | 火力覆盖 | 全场一次，5×5范围所有单位-5HP（含友军） |
| **拜隆** | 增援 + 月面回复 | 友军可分担伤害；月面地形每回合回复4HP |
| **马克西翁** | 奇袭 + 隐匿 | 跳过回合抢占攻击；未攻击单位不可被敌军选中 |

### 3.8 战场地形

| 地形 | 效果 |
|------|------|
| 普通格 | 无特殊效果 |
| 母舰 | 地球联合出击/回复点 |
| 月面 | 拜隆单位每回合+4HP |
| 基地 | 可藏有核心单位 |
| 防御层 | 距离1以外单位不可越过 |
| 太空 | 无重力，移动判定特殊 |

## 四、技术架构

### 4.1 整体架构

```
┌─────────────────────────────────────────────────────────┐
│                      浏览器（用户）                      │
│   Vue3 + PixiJS（画战场、显示棋子）                       │
└─────────────────────┬───────────────────────────────────┘
                      │ 网络请求
┌─────────────────────▼───────────────────────────────────┐
│                    服务器                               │
│   ┌─────────┐  ┌─────────┐  ┌─────────┐                │
│   │ 认证服务 │  │ 战斗服务 │  │ 地图服务 │                │
│   │  3005   │  │  3003   │  │  3002   │                │
│   └─────────┘  └─────────┘  └─────────┘                │
│                                                         │
│   ┌─────────┐  ┌─────────┐                            │
│   │ 通讯服务 │  │格纳库服务│                            │
│   │  3004   │  │  3001   │                            │
│   └─────────┘  └─────────┘                            │
│                                                         │
│   PostgreSQL 数据库                                     │
└─────────────────────────────────────────────────────────┘
```

### 4.2 技术选型

| 部分 | 使用的技术 | 用途 |
|------|-----------|------|
| 前端 | Vue3 + PixiJS | 画六角形地图、显示动画 |
| 后端 | Express | 处理游戏逻辑、存储数据 |
| 数据库 | PostgreSQL | 保存用户、机甲、战场数据 |
| 通信 | Socket.io | 实时对战时的消息传递 |
| 部署 | Docker | 方便在不同电脑上运行 |

### 4.3 为什么选这些技术？

| 技术 | 原因 |
|------|------|
| **Vue3** | 容易学、社区大、文档多，AI能生成大量代码 |
| **PixiJS** | 做游戏画面最流行的工具，性能好，适合六角格地图 |
| **PostgreSQL** | 稳定、免费、能存复杂数据 |
| **Express** | 简单、灵活，适合游戏后端 |

## 附录：术语表

| 术语 | 解释 |
|------|------|
| MVP | Minimum Viable Product，最小可行产品，先做最核心的功能 |
| 六角格 | 六边形的格子，战棋游戏常用 |
| 回合制 | 玩家轮流行动，不是同时操作 |
| 前端 | 用户看到的界面、网页 |
| 后端 | 服务器上处理数据、逻辑的部分 |
| 数据库 | 存储用户数据的地方 |
