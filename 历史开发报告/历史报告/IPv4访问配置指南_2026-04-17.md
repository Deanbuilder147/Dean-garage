## 防火墙配置

### 检查防火墙状态
```bash
# Ubuntu UFW
sudo ufw status

# 如果防火墙开启，需要放行端口
sudo ufw allow 5173/tcp
sudo ufw allow 5174/tcp
sudo ufw reload
```

### 云服务器安全组

如果你使用的是云服务器（阿里云、腾讯云、AWS 等），需要在控制台配置安全组：

**阿里云 ECS**:
1. 登录阿里云控制台
2. 进入 ECS 实例详情
3. 点击"安全组" → "配置规则"
4. 添加入站规则：
   - 端口范围：5173/5173, 5174/5174
   - 授权对象：0.0.0.0/0
   - 协议：TCP

**腾讯云 CVM**:
1. 登录腾讯云控制台
2. 进入安全组管理
3. 添加入站规则：
   - 类型：自定义
   - 端口：5173, 5174
   - 来源：0.0.0.0/0

**AWS EC2**:
1. 登录 AWS 控制台
2. 进入 Security Groups
3. 添加入站规则：
   - Type: Custom TCP
   - Port: 5173, 5174
   - Source: 0.0.0.0/0

## Vite 配置说明

### chess-system/vite.config.js
```javascript
export default defineConfig({
  plugins: [vue()],
  server: {
    port: 5173,
    host: '0.0.0.0'  // 监听所有网络接口
  },
  preview: {
    port: 4173
  }
})
```

### battle-map/vite.config.js
```javascript
export default defineConfig({
  plugins: [vue()],
  server: {
    port: 5174,
    host: '0.0.0.0',  // 监听所有网络接口
    proxy: {
      '/api/map': { /* ... */ }
    }
  }
})
```

**配置说明**:
- `host: '0.0.0.0'` - 监听所有 IPv4 地址
- `port: 5173/5174` - 指定端口号
- 默认情况下 Vite 只监听 `localhost`，配置后才能从外部访问

## 生产环境部署建议

### ⚠️ 开发服务器 vs 生产服务器

当前使用的是 **Vite 开发服务器**，适合开发和测试，不建议用于生产环境：

**开发服务器的限制**:
- ❌ 性能未优化
- ❌ 没有安全加固
- ❌ 单线程运行
- ❌ 不适合高并发

**生产环境部署**:

1. **构建静态文件**
```bash
cd apps/chess-system
npm run build  # 输出到 dist/ 目录

cd apps/battle-map
npm run build  # 输出到 dist/ 目录
```

2. **使用 Nginx 部署**
```nginx
# /etc/nginx/sites-available/dean-garage

server {
    listen 80;
    server_name your-domain.com;

    # 棋子管理系统
    location /chess/ {
        alias /home/agentuser/Dean-garage/apps/chess-system/dist/;
        try_files $uri $uri/ /index.html;
    }

    # 战斗地图系统
    location /battle/ {
        alias /home/agentuser/Dean-garage/apps/battle-map/dist/;
        try_files $uri $uri/ /index.html;
    }
}
```

3. **重启 Nginx**
```bash
sudo nginx -t
sudo systemctl reload nginx
```

## 常见问题

### Q1: 无法从其他设备访问
**检查项**:
1. ✅ 服务器是否监听 0.0.0.0：`netstat -tlnp | grep 5173`
2. ✅ 防火墙是否放行：`sudo ufw status`
3. ✅ 云安全组是否配置：检查控制台
4. ✅ 网络是否可达：`ping 10.0.0.9`

### Q2: 访问速度慢
**可能原因**:
- 网络延迟高
- 开发服务器性能限制
- 带宽不足

**解决方案**:
- 使用生产构建 + Nginx
- 开启 CDN 加速
- 优化资源大小

### Q3: 端口被占用
**解决**:
```bash
# 查看端口占用
lsof -i :5173

# 修改 vite.config.js 使用其他端口
server: {
  port: 5175,  # 改为其他端口
  host: '0.0.0.0'
}
```
