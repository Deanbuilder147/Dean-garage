## 二、问题二：Excel 导入显示"解析失败"

### 2.1 请求链路追踪

```
前端 NewUnitEditorView.vue
  handleFileSelect() → hangarAPI.parseExcel(formData)
    ↓
client.js: POST /api/units/parse-excel (FormData)
    ↓
Nginx: location /api/units → proxy_pass mecha-gateway:3006
    ↓
Gateway units.ts 路由表:
  GET    /api/units           ✅
  POST   /api/units           ✅
  POST   /api/units/generate  ✅
  GET    /api/units/factions  ✅
  PUT    /api/units/:unitId   ✅
  DELETE /api/units/:unitId   ✅
  POST   /api/units/parse-excel     ❌ 不存在!
  POST   /api/units/create-from-json ❌ 不存在!
    ↓
Express 404 → { "error": "NOT_FOUND", "message": "端点不存在" }
    ↓
前端 catch: alert('解析失败: 端点不存在')
```

### 2.2 根因

**Gateway `units.ts`（第 14-206 行）仅注册了 6 个端点**，缺少以下 2 个 Excel 导入必需的端点：

| 缺失端点 | 前端调用 | 旧实现位置 |
|:---|:---|:---|
| `POST /api/units/parse-excel` | `hangarAPI.parseExcel(fd)` | `services/hangar-service/src/routes/units.js` (L823-L870) |
| `POST /api/units/create-from-json` | `hangarAPI.createFromJson(data)` | `services/hangar-service/src/routes/units.js` (L872-L922) |

**原因**: 旧 hangar-service (port 3002) 容器已在 Phase 29 大一统改造中退役，Excel 导入功能未被迁移到新网关。容器现状：

```
✅ mecha-gateway      :3006  (运行中)
✅ mecha-frontend     :8081  (运行中)
✅ mecha-comm         :3005  (运行中)
✅ mecha-battle-db    :5432  (运行中)
❌ mecha-hangar       :3002  (未运行/已退役)
```

### 2.3 旧 Excel 解析实现的依赖

旧 hangar-service 中 parse-excel 依赖以下模块：

| 依赖模块 | 文件 | 功能 |
|:---|:---|:---|
| `xlsx` 库 | npm 包 | SheetJS — 读取 .xlsx 文件 |
| `multer` | npm 包 | multipart/form-data 文件上传中间件 |
| `excel-parser.js` | `services/hangar-service/src/services/excel-parser.js` | 配置化 Excel 解析器 |
| `excel-validator.js` | `services/hangar-service/src/services/excel-validator.js` | 数据验证器 |
| `excel-template.js` | `services/hangar-service/src/config/excel-template.js` | Excel 列/行/技能映射配置 |
| `unit-import-service.js` | `services/hangar-service/src/services/unit-import-service.js` | 事务化 DB 写入 |

### 2.4 迁移到 Gateway 所需工作

要将 Excel 导入功能迁移到网关 `units.ts`，需要：

1. **安装依赖**: `xlsx` + `multer` 加入 `backend-gateway/package.json`
2. **迁移 excel-parser.js**: 将旧解析器转为 TypeScript，适配新单位 schema
3. **迁移 excel-template.js**: 列映射配置保持不变
4. **新增端点**: 在 `units.ts` 中注册 `POST /api/units/parse-excel` 和 `POST /api/units/create-from-json`
5. **Schema 适配**: 旧 hangar 用中文字段名（`main_格斗`、`left_type`），新网关用 JSON 字段（`stats`、`skills`、`attributes`）
6. **认证集成**: 使用 `authenticate` + `requireAuth` 中间件
