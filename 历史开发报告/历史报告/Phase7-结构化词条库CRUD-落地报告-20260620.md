## 二、后端：原子 CRUD 基础设施

### 2.1 configLoader.cjs

| 新增 | 说明 |
|------|------|
| `deleteSkills(skillKeys)` | 接收键名数组，原子删除 `config.skills` 中的词条并写盘 |
| `saveGlossaryConfig()` 升级 | 检测 `_delete_skills` 指令，**先执行删除，再深度合并剩余内容** |

```
_delete_skills 工作流:
  POST { _delete_skills: ["old_block"], skills: { new_block: {...} } }
  → deleteSkills(["old_block"]) 先执行
  → deepMerge(remaining) 后执行
  → 原子写入磁盘
```

### 2.2 battles.js 路由升级

`POST /api/combat/glossary-config` 新增能力：

- **CREATE**: `skills: { new_key: {...} }` → 深度合并添加
- **DELETE**: `_delete_skills: ["key1", "key2"]` → 原子删除
- **UPDATE**: `skills: { existing_key: {...} }` → 深度合并更新
- **组合操作**: 同一请求中可同时包含 `_delete_skills` + `skills`，保证原子性

9 个技能全面升级，新增 5 个通用结构化字段：

## 三、词条库 UI：GlossaryView.vue 全量重写 (414→611 行)

### 3.1 新架构

```
[ 操作栏 ]
  ├── [ 编辑模式 ] 切换
  ├── [ + 添加新词条 ] → addNewSkill() 动态插入
  ├── [ 保存并同步规则 ] → saveConfig() 含 _delete_skills
  └── ⚠ N 个待删除 (pendingDeletes 计数器)

[ 技能词条面板 ]
  ┌─ 词条卡片 (v-for skills) ─────────────────┐
  │ KEY: [block]  名称: [格挡]  分类: [melee]   [✕ 删除] │
  │ 描述: [受攻击时伤害减少]                     │
  │                                              │
  │ 通用字段:                                    │
  │  施放对象: [enemy ▼]  施放距离: [0] 格      │
  │  AOE半径: [0] (单体)   基础伤害: [0]        │
  │  附加效果: [灼烧] [眩晕] [断腿] ...          │
  │                                              │
  │ ▶ 高级参数 (类型专属)                        │
  │   └ reduction: [2]  trigger: [on_attacked]   │
  └──────────────────────────────────────────────┘
```

### 3.2 关键功能

| 功能 | 实现 |
|------|------|
| **添加词条** | `addNewSkill()` → 动态插入 `new_skill_{timestamp}` 到 `skills` 对象 |
| **删除词条** | `deleteSkill(key)` → 标记到 `pendingDeletes[]`，保存时提交 `_delete_skills` |
| **KEY 重命名** | `skillKeyEdits` 追踪编辑，`onSkillKeyBlur` 检测冲突后重命名 |
| **通用字段** | 5 个字段统一布局：`target_filter`(下拉) / `cast_range`(数字) / `aoe_radius`(数字) / `base_damage`(数字) / `status_effects`(多选标签) |
| **高级参数** | `getAdvancedParams()` 过滤掉通用字段，余下类型专属参数折叠显示 |
| **系统参数** | 保留 ambush / fog_of_war / crit 编辑面板 |

### 3.3 状态效果标签 UI

可用效果：灼烧 burn / 眩晕 stun / 断腿 disable / 减速 slow / 中毒 poison / 冰冻 freeze

点击标签切换选中，`toggleEffect(skill, value)` 操作 `skill.status_effects` 数组。

## 五、SkillExecutor：通用字段驱动

### 5.1 新增方法

| 方法 | 用途 |
|------|------|
| `_getUniversalFields(skillType)` | 返回 `{ target_filter, cast_range, aoe_radius, base_damage, status_effects }` |
| `getSkillRange(skillType)` | 返回 `{ min, max }` 供前端 BFS 寻路高亮 |
| `getAoeRadius(skillType)` | 返回溅射半径（0=单体, >0=六边形溅射） |

### 5.2 方法升级（通用字段优先，fallback 旧字段）

| 方法 | 升级内容 |
|------|----------|
| `executeCounter` | 施放距离 → `cfg?.cast_range ?? skillRange ?? 1` |
| `executeThrow` | 施放距离 → `cfg?.cast_range ?? cfg?.max_range ?? 3` |
| `executeSweep` | 施放距离 → `cfg?.cast_range ?? cfg?.max_range ?? 2`；伤害消息 → `cfg?.base_damage` |
| `executeFocusedFire` | 基础伤害 → `cfg?.base_damage ?? cfg?.bonus ?? 4` |
| `canSniper` | 施放距离 → `cfg?.cast_range ?? cfg?.max_range ?? 6` |
