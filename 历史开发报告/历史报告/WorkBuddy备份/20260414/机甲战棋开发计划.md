# 机甲战棋网页游戏 - 开发计划

> 项目启动：2026-03-31
> 作者：Dean

---

## 一、项目概述

基于 mecha-battle-pack 规则开发网页战棋游戏，参考 GBA 超级机器人大战风格。

### 游戏模式
| 模式 | 说明 |
|------|------|
| **多人对战** | 多阵营 PVP，支持 2-6 人在线对战 |
| **RPG 模式** | 双阵营对战，玩家 vs AI 或合作推图 |

### 核心特色
- 六边形棋盘策略
- 三大阵营独特玩法
- 完整的机甲定制系统
- 可视化管理后台

---

## 二、技术方案

### 前端技术栈
```
框架：Vue 3 + TypeScript
UI库：Element Plus（管理后台） + 自定义游戏UI
游戏引擎：PixiJS（2D渲染，适合写实风格）
棋盘：hexagrid.js 或 自研六边形系统
状态管理：Pinia
网络：Socket.io-client（实时对战）
```

### 后端技术栈
```
框架：Node.js + Express 或 NestJS
数据库：SQLite（开发）→ PostgreSQL（生产）
认证：JWT + bcrypt
实时通信：Socket.io
管理后台：内置 Admin Panel
```

├── client/                    # 前端
