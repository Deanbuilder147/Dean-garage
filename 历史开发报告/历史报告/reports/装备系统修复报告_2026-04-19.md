## 修复内容

### 1. AOE 技能隐身交互修复 ✅

**问题:** 地球联合的炮击技能 (artillery) 在攻击范围内单位时，没有检查隐身状态，隐身单位无法闪避 AOE 伤害。

**修复文件:** `services/combat-service/src/services/combatCore/factionSkillRegistry.cjs`

**修复内容:**
- 在 artillery 技能的 execute 方法中添加隐身检查逻辑
- 隐身单位有 50% 概率闪避 AOE 伤害 (掷骰 4,5,6 成功)
- 闪避成功的单位会被记录到 `units_affected` 数组，标记 `evasion: true`
- 添加详细的日志记录，包括闪避原因和掷骰结果

**代码片段:**
```javascript
// ========== 隐身检查 ==========
// AOE 攻击也需要检查隐身状态
let shouldEvade = false;
let evasionReason = '';

if (unit.stealth === true) {
  // 隐身单位有 50% 概率闪避 AOE 伤害
  const evasionRoll = Math.floor(Math.random() * 6) + 1;
  const evasionThreshold = 3; // 4,5,6 成功 = 50% 概率
  
  if (evasionRoll >= evasionThreshold) {
    shouldEvade = true;
    evasionReason = `隐身闪避 (掷骰${evasionRoll}>=${evasionThreshold})`;
  }
}

// 如果闪避成功，跳过此单位
if (shouldEvade) {
  result.units_affected.push({
    unit_id: unit.id,
    unit_name: unit.name,
    faction: unit.faction,
    distance: distance,
    damage_taken: 0,
    hp_remaining: unit.hp,
    evasion: true,
    evasion_reason: evasionReason
  });
  
  result.logs.push({
    type: 'artillery_evaded',
    unit_name: unit.name,
    faction: unit.faction,
    reason: evasionReason
  });
  return; // 跳过此单位
}
// ========== 隐身检查结束 ==========
```

### 2. 装备管理器实现 ✅

**问题:** `equipManager.cjs` 只有空壳方法，返回的武器加成和防具减伤都是 0。

**修复文件:** `services/combat-service/src/services/combatCore/equipManager.cjs`

**实现的方法:**

1. **getWeaponBonus(unit, attackType)** - 获取武器加成
   - 检查左手、右手、额外装备槽的武器
   - 根据攻击类型 (melee/ranged) 返回对应的加成值
   - 返回总加成值和详细来源列表

2. **getArmorDefense(unit)** - 获取防具防御
   - 检查左手、右手、额外装备槽的防具
   - 只有耐久度>0 的防具才提供防御
   - 返回总防御值和详细来源列表

3. **consumeArmorDurability(unit)** - 消耗防具耐久
   - 每次受到攻击消耗 1 点耐久
   - 耐久归零时防具被摧毁
   - 返回消耗和摧毁记录

4. **getResistances(unit)** - 获取抗性列表
   - 收集所有装备提供的抗性类型
   - 用于后续的抗性伤害减免计算

5. **hasResistance(unit, damageType)** - 检查特定抗性
   - 判断单位是否拥有某种伤害类型的抗性

6. **getAllEquipment(unit)** - 获取完整装备列表
   - 返回单位所有装备的详细信息

**测试覆盖率:** ✅ 7/7 测试通过

## 技术细节

### 装备数据结构

单位对象现在支持以下装备属性:

```javascript
{
  // 左手装备
  left_hand_type: 'weapon' | 'armor' | 'system' | null,
  left_hand_name: string | null,
  left_hand_melee: number,
  left_hand_ranged: number,
  left_hand_defense: number,
  left_hand_durability: number,
  left_hand_resistance: 'kinetic' | 'energy' | 'explosive' | null,
  
  // 右手装备 (同上)
  right_hand_type: ...,
  right_hand_name: ...,
  right_hand_melee: ...,
  right_hand_ranged: ...,
  right_hand_defense: ...,
  right_hand_durability: ...,
  right_hand_resistance: ...,
  
  // 额外装备槽 (同上)
  extra_type: ...,
  extra_name: ...,
  extra_melee: ...,
  extra_ranged: ...,
  extra_defense: ...,
  extra_durability: ...,
  extra_resistance: ...
}
```

### 伤害计算流程

```
1. 基础攻击力 (格斗/射击)
   ↓
2. 机动差修正 (攻击方机动 - 防御方机动)
   ↓
3. 武器加成 ← EquipmentManager.getWeaponBonus()
   ↓
4. Buff 加成 ← BuffManager
   ↓
5. 暴击判定 (10% 概率 ×1.5 倍)
   ↓
6. 基础伤害 = 攻击 + 修正 + 加成
   ↓
7. 防御减伤 ← EquipmentManager.getArmorDefense()
   ↓
8. 最终伤害 = 基础伤害 - 防御减伤
   ↓
9. 耐久度消耗 ← EquipmentManager.consumeArmorDurability()
```
