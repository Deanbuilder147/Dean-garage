### 差异汇总
- **唯一不一致项：格挡（block）**。设计文档《战斗规则·设定器》表将其「释放范围」写为「周围一圈」，而线上词条库数值为 `cast_range=0`（仅自身 / 被动触发，无目标距离）。两者口径不同：设计稿可能意在表达“敌人需处于相邻 1 格才触发格挡”，而词条库实现为纯自身被动（不依赖邻接）。**建议在词条库或设计稿中统一口径**（多数情况下 block 作为“受击被动”应以自身为准，若需邻接条件则应补 `cast_range=1` 并加触发判定）。
- 其余 8 个词条（反击 / 长柄 / 补给 / 扫射 / 稳定 / 助攻 / 守护 / 阻碍）的设计稿「释放范围」与词条库数值**完全对应**，无数值冲突。

## 三、说明与口径

- **技能 → 词条 映射依据**：单位技能记录的 `description` / `effect` 中文字段（长柄/反击/扫射/格挡/稳定/助攻/阻碍/守护/补给…）与词条库中 `label` 对应；`补给（双槽）` 归并到 `supply(补给)`。
- **攻击距离字段含义**（词条库）：`cast_range`=攻击/施法距离，`min_cast_range`=最小施放距离，`max_range`/`min_range`=范围边界，`aoe_radius`=范围半径；无相关字段记为「—」。
- **两份数据库比对**：逐项 diff 差异 0 处（容器内直接比对复核，两份副本在攻击距离字段上完全一致）。
- **关于「单位自带范围」**：`xexm-000` 的单位技能自身内嵌范围（SQLite units 表：格斗 range=1、射击 range=3、电磁炮 range=4、突刺盾 range=1），与词条库取值一致；WeirdNova 与麦德雷特据点突击型的技能未内嵌范围，完全依赖词条库。
- **三个棋子的选取**：取自当前单位库中带真实战斗技能、非测试用途的 3 个机体（WeirdNova / 麦德雷特据点突击型 / xexm-000）；其余单位为测试体（烟雾测试/烟雾战斗）或技能为空，未计入。
