## 🎯 核心功能

### 1. 单位移动类型

```javascript
MOVE_TYPES = {
  LAND: 'land',  // 陆地单位
  AIR: 'air',    // 空中单位
  SEA: 'sea'     // 海上单位
}
```

### 2. 地形通行性

| 地形类型 | 陆地 | 空中 | 海上 |
|---------|------|------|------|
| plain (平原) | ✅ | ✅ | ❌ |
| mountain (山地) | ✅ | ✅ | ❌ |
| forest (森林) | ✅ | ✅ | ❌ |
| base (基地) | ✅ | ✅ | ❌ |
| ruin (废墟) | ✅ | ✅ | ❌ |
| lunar (月面) | ✅ | ✅ | ❌ |
| crater (陨石坑) | ✅ | ✅ | ❌ |
| water (水域) | ❌ | ✅ | ✅ |
| lava (岩浆) | ❌ | ✅ (消耗 2) | ❌ |

### 3. 移动消耗修正

**陆地单位:**
- 平原/森林/基地/月面：1 点移动力
- 山地/废墟/陨石坑：2 点移动力
- 水域/岩浆：不可通行 (999)

**空中单位:**
- 所有地形：1 点移动力
- 岩浆：2 点移动力 (高温影响)

**海上单位:**
- 水域：1 点移动力
- 所有陆地地形：不可通行 (999)

### 4. 攻击克制关系

| 攻击方 → 防御方 | 陆地 | 空中 | 海上 |
|----------------|------|------|------|
| **陆地** | 0 | -1 | +1 |
| **空中** | 0 | 0 | +2 |
| **海上** | -999 (无法攻击) | -2 | 0 |

**详细说明:**
- **地对空 -1:** 空中目标难以命中
- **地对海 +1:** 海面固定靶优势
- **空对海 +2:** 完全制空权，压倒性优势
- **海对陆 -999:** 海上单位无法攻击陆地目标
- **海对空 -2:** 海上单位对空极度劣势

### 5. 防御闪避修正

| 防御方 ← 攻击方 | 陆地 | 空中 | 海上 |
|----------------|------|------|------|
| **陆地** | 0 | +1 | 0 |
| **空中** | -1 | 0 | -1 |
| **海上** | 0 | +2 | 0 |

**详细说明:**
- **地对空 +1:** 陆地单位容易闪避空中攻击 (攻击轨迹明显)
- **空对地 -1:** 空中单位难以闪避俯冲攻击 (突然性)
- **海对空 +2:** 海上单位容易闪避空中攻击 (目标明显)

## 🔧 API 接口

### 核心方法

```javascript
// 检查单位是否可以进入某地形
UnitTypeManager.canMoveTo(moveType, terrain)
// 返回：boolean

// 获取地形移动消耗
UnitTypeManager.getMoveCost(moveType, terrain)
// 返回：number (999 表示不可通行)

// 获取攻击克制修正
UnitTypeManager.getAttackModifier(attackerType, defenderType)
// 返回：number

// 获取防御闪避修正
UnitTypeManager.getDefenseModifier(defenderType, attackerType)
// 返回：number

// 检查攻击是否有效
UnitTypeManager.canAttack(attackerType, defenderType)
// 返回：{ valid: boolean, reason: string }

// 计算完整的类型克制效果
UnitTypeManager.calculateTypeEffectiveness(attacker, defender)
// 返回：{ attacker_type, defender_type, attack_modifier, 
//         defense_modifier, can_attack, reason, advantage, description }

// 验证单位移动路径是否合法
UnitTypeManager.validateMovement(moveType, path, maxMovement)
// 返回：{ valid: boolean, totalCost: number, blockedAt: number|null, reason: string }
```

## 🎮 游戏设计影响

### 战术多样性

1. **制空权重要性:** 空中单位对海上单位有 +2 攻击加成，强调制空权
2. **地形利用:** 陆地单位可以利用山地、森林等地形阻挡敌军
3. **兵种配合:** 需要陆海空三军配合，单一兵种无法应对所有情况

### 平衡性考虑

1. **地对空劣势:** 鼓励玩家使用空中单位压制地面部队
2. **海对陆限制:** 海军无法直接攻击陆地目标，需要空军支援
3. **空中全能:** 空中单位可以到达所有地形，但可能有其他限制 (如燃料、基地依赖)
