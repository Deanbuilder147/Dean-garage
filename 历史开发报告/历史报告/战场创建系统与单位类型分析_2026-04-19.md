## 📊 当前系统架构

### 1. Map Service (地图服务)

**文件:** `services/map-service/src/routes/battlefields.js`

#### 核心功能
- ✅ 战场 CRUD (创建/读取/更新/删除)
- ✅ 地形编辑器接口
- ✅ 六角格路径计算
- ✅ 出生点管理 (mothership/base)

#### 数据库表结构

**battlefields 表:**
```sql
CREATE TABLE battlefields (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  width INTEGER NOT NULL DEFAULT 20,
  height INTEGER NOT NULL DEFAULT 30,
  terrain TEXT DEFAULT '{}',  -- JSON 格式：{"q,r": "terrain_id"}
  type TEXT DEFAULT 'standard',
  is_public INTEGER DEFAULT 1,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
)
```

**terrain_types 表:**
```sql
CREATE TABLE terrain_types (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  terrain_id TEXT UNIQUE NOT NULL,
  name TEXT NOT NULL,
  movement_cost INTEGER DEFAULT 1,
  defense_bonus INTEGER DEFAULT 0,
  can_spawn INTEGER DEFAULT 1,
  color TEXT DEFAULT '#888888',
  description TEXT
)
```

#### 当前地形类型 (6 种)

| terrain_id | 名称 | 移动消耗 | 防御加成 | 可出生 | 颜色 |
|-----------|------|---------|---------|--------|------|
| empty | 空地 | 1 | 0 | ✅ | #88CC88 |
| mountain | 山地 | 3 | 20 | ❌ | #886644 |
| forest | 森林 | 2 | 10 | ✅ | #228822 |
| water | 水域 | 99 | 0 | ❌ | #4488FF |
| mothership | 母舰 | 1 | 0 | ✅ | #FFD700 |
| base | 基地 | 1 | 0 | ✅ | #FF4444 |

#### API 接口

```javascript
GET    /battlefields                    // 获取战场列表
GET    /battlefields/all                // 获取所有公共战场
GET    /battlefields/:id                // 获取战场详情
GET    /battlefields/:id/spawn-points   // 获取出生点
POST   /battlefields                    // 创建战场
PUT    /battlefields/:id                // 更新战场
DELETE /battlefields/:id                // 删除战场

GET    /battlefields/terrain/types      // 获取地形类型列表
POST   /battlefields/:id/terrain        // 批量更新地形
DELETE /battlefields/:id/terrain        // 清除指定地形

POST   /battlefields/utils/path         // 计算路径 (A*)
POST   /battlefields/utils/range        // 获取范围内格子
```

### ⚠️ 缺失的集成

#### 1. 单位移动类型字段缺失

**问题:** Hangar Service 的 units 表没有 `move_type` 字段

**当前表结构:**
```sql
units (
  ...
  main_type TEXT DEFAULT '机体',  -- 这是装备类型 (机体/武器/防具), 不是移动类型
  ...
)
```

**需要添加:**
```sql
ALTER TABLE units ADD COLUMN move_type TEXT DEFAULT 'land';
-- 或者在创建新单位时指定
```

#### 2. 地形类型不匹配

**问题:** Map Service 的地形 ID 与 UnitTypeManager 的地形不一致

**Map Service 地形:**
- empty, mountain, forest, water, mothership, base

**UnitTypeManager 地形:**
- plain, mountain, forest, base, ruin, lunar, crater, water, lava

**解决方案:** 需要统一地形 ID 命名

#### 3. 战斗系统未集成单位类型

**问题:** Combat Service 的战斗计算未使用 UnitTypeManager

**当前流程:**
```
damagePipe.cjs → 计算伤害 → 未考虑单位类型克制
```

**需要集成:**
```javascript
const typeEffect = UnitTypeManager.calculateTypeEffectiveness(attacker, defender);
attackBonus += typeEffect.attack_modifier;
defenseBonus += typeEffect.defense_modifier;
```

#### 4. 移动系统未集成地形验证

**问题:** 单位移动未检查移动类型和地形通行性

**当前:** 单位可以移动到任何地形

**需要:**
```javascript
const canMove = UnitTypeManager.canMoveTo(unit.move_type, targetTerrain);
const moveCost = UnitTypeManager.getMoveCost(unit.move_type, targetTerrain);
```

## 📋 建议的单位类型模型

基于游戏设计，建议以下单位分类:

### 陆地单位 (land) - 主力部队

| 单位名称 | 说明 | 典型地形 |
|---------|------|---------|
| 机甲 (Mecha) | 主力作战单位 | 平原/山地/森林 |
| 战车 (Tank) | 重型火力 | 平原/基地 |
| 步兵 (Infantry) | 轻型单位 | 森林/废墟 |
| 移动基地 (Mobile Base) | 补给/修复 | 平原/基地 |

### 空中单位 (air) - 制空权

| 单位名称 | 说明 | 特性 |
|---------|------|------|
| 战斗机 (Fighter) | 制空作战 | +2 vs 海上 |
| 轰炸机 (Bomber) | 对地攻击 | 无视地形 |
| 运输机 (Transport) | 单位运输 | 高移动力 |
| 无人机 (Drone) | 侦察/骚扰 | 低消耗 |

### 海上单位 (sea) - 水域控制

| 单位名称 | 说明 | 限制 |
|---------|------|------|
| 战舰 (Battleship) | 重火力 | 只能在水域 |
| 航母 (Carrier) | 搭载飞机 | 需要水域 |
| 潜艇 (Submarine) | 隐蔽攻击 | 水域专属 |
| 运输舰 (Transport) | 两栖作战 | 水域/基地 |

## 🎮 游戏设计建议

### 1. 阵营特色单位类型

**地球联邦 (Earth)**
- 侧重陆地单位 (机甲 + 战车组合)
- 空中单位以支援为主 (运输机 + 无人机)
- 无海军 (设定上为内陆势力)

**拜火教 (Byron)**
- 均衡的陆空力量
- 特色：高速空中单位
- 少量海军 (如果地图有水域)

**马克西恩 (Maxion)**
- 海军强国 (如果地图有水域)
- 重型空中单位 (轰炸机)
- 陆地单位较少但质量高

### 2. 地图设计原则

**小型地图 (20x30)**
- 以陆地地形为主
- 少量水域作为障碍
- 强调陆地作战

**中型地图 (30x40)**
- 陆地 + 水域混合
- 需要陆海空协同
-  Strategic depth

**大型地图 (40x50+)**
- 多岛屿设计
- 海军至关重要
- 空军争夺制空权

### 3. 平衡性考虑

**空中单位过强问题:**
- 可以到达所有地形
- 对海军 +2 攻击
- **限制方案:**
  - 降低 HP 或防御
  - 增加维护费用
  - 需要基地补给 (燃料限制)
  - 地对空 -1 修正作为平衡

**海军单位限制:**
- 只能在水域移动
- 无法攻击陆地
- **补偿:**
  - 高 HP/高火力
  - 对空闪避 +2
  - 可以作为移动基地
