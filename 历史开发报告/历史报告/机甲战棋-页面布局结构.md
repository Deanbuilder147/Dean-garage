# 机甲战棋 - 页面布局结构

## 页面列表

| 路由 | 页面名称 | 功能 |
|------|----------|------|
| `/login` | 登录页 | 用户登录 |
| `/register` | 注册页 | 用户注册 + 阵营选择 |
| `/home` | 主页 | 功能导航卡片 |
| `/units` | 机甲库 | 棋子列表 + 创建/编辑 |
| `/battlefields` | 战场编辑器 | 六角格地图编辑 |
| `/battle/:id` | 战斗页 | PixiJS 战场渲染 |
| `/preparation/:roomId` | 整备室 | 阵营选择 + 棋子部署 |
