## 〇、数据模型前提（必须明确）

Excel 导入后，每个"部件"是一个 `ParsedUnit`，含两个独立维度：

| 维度 | 字段 | 取值 | 来源 |
|------|------|------|------|
| **挂载槽位** | `unitKey`（键名） | 主机体 / 跟随 / 左手 / 右手 / 其它 | A 列经 `resolveUnitKey` 归一 |
| **部件类型** | `type` | 机体 / 武器 / 防具 / 载具 / 背包 / 跟随(royroy) / … | B 列原文 |

> ⚠️ 修正规则全部基于 **`type`（部件类型）**，不是槽位。

## 一、当前实现（问题所在）

### 聚合逻辑（`excel-schema-normalizer.ts`）
```js
totalMelee     = sumPartStat(parsed.units, '格斗')   // 全部部件
totalShooting  = sumPartStat(parsed.units, '射击')   // 全部部件
totalStructure = sumPartStat(parsed.units, '结构')   // 全部部件
totalMobility  = sumPartStat(parsed.units, '机动')   // 全部部件
```
### 映射（`mapToUnitStats`）
```js
hp      = structure * 5 + 20
armor   = floor(structure * 0.25)
shield  = 0
attack  = melee * 2 + 5
defense = floor(mobility * 0.3)
speed   = 2 + floor(mobility / 20)
range   = 1 + floor(shooting / 25)
```
**问题**：防具/载具/背包/跟随 的格斗射击被累加进 `attack`/`range`；所有部件结构当单位血量；机动无差别全加；无耐久度、无伤害分担概念。

## 二、修正规则（用户给出，含答疑）

### A. 数值聚合规则
1. **格斗、射击不叠加** `royroy(跟随)`、`防具`、`载具`、`背包` 的格斗/射击值 → 仅 `机体` + `武器` 计入 `attack` / `range`。
2. **武器、载具的结构值 = 该装备耐久度**（即该物品携带技能的可使用次数）；**防具、背包基础耐久度 = 5**。
3. **防具、背包的 hp = 结构值 × 2**。
4. **shield = 机体携带的防具/背包各自的 hp，分开计算**；同时装备两样时，每次受击分别扣除这两个装备的 hp（答疑⑤）。

### B. 护甲 / 背包 伤害分担（答疑①⑤）
- **防具**携带时，每次受击**分担 3 点伤害**；当该防具 **hp 或 durability = 0** 时自动舍弃。
- **背包**若带结构属性，同样每次受击分担 3 点伤害；hp 或 durability = 0 时舍弃。
- 即：防具/背包各自是独立的伤害吸收槽，每槽每次最多吸 3 点。

### C. 跟随（royroy）规则（答疑②）
- 跟随自身**无耐久度限制**；布置上场后可被攻击，**hp = 0 时舍弃该随从**。

### D. 机动值规则（补充）
1. **移动范围** = `机体机动 + 载具机动 + 背包机动`；载具/背包 **durability = 0 时该部件机动失效**（不计入）。
2. **攻击伤害计算的机动值差额**：`差额 = 攻方有效机动 − 守方有效机动`；若 `差额 > +5`，则 `差额 = 5`（封顶）。
3. **武器机动**只在「使用该武器技能」时的差额计算中生效。
4. **防具机动**只在「携带方作为被攻击方」时的差额计算中生效。
5. **royroy 机动**生效条件 = 武器与防具（即：royroy 作为攻方用其技能时、作为守方时生效）；**但 royroy 机动与机体机动不互通**（各自独立成池，不相加）。

### E. 兼容性（答疑④）
- 现有 `units` 表旧公式 stats 不会自动变 → 需写**一次性迁移脚本**重算。

## 三、逐项对比表（当前 → 修正后）

| 数值 / 概念 | 当前算法 | 修正后算法 |
|------|----------|------------|
| **格斗合计** | Σ 全部部件格斗 | Σ_{type∈{机体,武器}} 格斗 |
| **射击合计** | Σ 全部部件射击 | Σ_{type∈{机体,武器}} 射击 |
| **attack** | 格斗合计×2+5 | （新格斗合计）×2+5 |
| **range** | 1+floor(射击/25) | 1+floor(新射击/25) |
| **主 hp** | 全结构×5+20 | 仅 **机体结构**×5+20 |
| **armor（护甲值）** | floor(全结构×0.25) | floor(**机体结构**×0.25)（建议；防具改为伤害分担槽，不再加甲，见 B） |
| **防具/背包 hp** | 无独立 hp | 各自 = 该部件**结构 × 2**（规则 3）；兼作 shield 吸收槽（规则 4） |
| **shield** | 0 | = 防具/背包各自 hp（分开计，各次受击分别扣，见 B/答疑⑤） |
| **耐久 durability** | 无 | 武器/载具 = 该部件结构；防具/背包 = 5；royroy/机体 = 无（royroy 用 hp 判定，答疑②） |
| **移动范围（新）** | 无（原 speed 代用） | **机体+载具+背包 机动**（载具/背包 durability=0 失效） |
| **机动值差额（新）** | 无 | 攻方有效机动 − 守方有效机动，>+5 封顶 5；按 D.3/4/5 上下文取有效机动 |
| **speed** | 2+floor(全机动/20) | 待确认：建议 = 2 + floor(移动范围/20)（见歧义⑥） |
| **defense** | floor(全机动×0.3) | 待确认：建议 = floor(机体机动×0.3)（见歧义⑥） |

### 修正后总公式（建议版 v2）
```
# —— 聚合（导入时算定）——
meleeSum = Σ 格斗 where type ∈ {机体, 武器}
shootSum = Σ 射击 where type ∈ {机体, 武器}
bodyStruct = 机体.结构
bodyMob    = 机体.机动

attack  = meleeSum*2 + 5
range   = 1 + floor(shootSum/25)
armor   = floor(bodyStruct*0.25)
hp      = bodyStruct*5 + 20                       # 主机体血量
shieldParts = [ 防具, 背包 ]                        # 各部件独立
  对每个 p ∈ shieldParts:
     p.hp        = p.结构 * 2                       # 规则3
     p.durability= (p.type==防具||p.type==背包) ? 5 : 0   # 规则2

# 每部件耐久（武器/载具）
durability[武器/载具] = 该部件.结构
durability[防具/背包] = 5
durability[机体/royroy] = 无

# —— 战斗期动态量 ——
移动范围 = bodyMob
         + (载具.机动 if 载具.durability>0)
         + (背包.机动 if 背包.durability>0)

机动值差额 = M_atk − M_def ;  if (M_atk − M_def) > 5 → 5
  M_atk = (攻方==机体) ? bodyMob + (activeWeapon.机动 if 用该武器技能)
        : (攻方==royroy) ? royroy.机动            # royroy 不互通
  M_def = (守方==机体) ? bodyMob + (armor.机动 if 守方带防具)
        : (守方==royroy) ? royroy.机动
```

## 四、必须修改的文件清单

## 七、已确认（用户答疑）& 仍需最终确认的接口细节

### 已确认（用户第七节答疑）
1. **防具/背包护甲**：防具携带时每次分担 3 点伤害；防具 hp 或 durability=0 时自动舍弃；背包带结构时同样每次分担 3 点。
2. **机体/跟随耐久**：跟随无耐久限制，但上场后可被攻击，hp=0 舍弃；机体仍用 hp（无耐久）。
3. **多件独立计次**：每个武器/防具耐久各自独立。
4. **兼容性**：写一次性迁移脚本重算旧单位。
5. **shield**：= 防具/背包各自 hp，分开计算，同时装备两样时每次受击分别扣两者 hp。

### 仍需最终确认的接口细节（实施前请拍板）
6. **speed / defense 的基数机动**：用户未重定义这两项。建议 `speed = 2 + floor(移动范围/20)`、`defense = floor(机体机动×0.3)`；若你另有口径请指明。
7. **royroy「不互通」的精确含义**：理解为 royroy 作为独立单位，其机动**不加入**机体机动池（机体攻击用 `机体+activeWeapon`，royroy 攻击用 `royroy.机动`）。若 royroy 与机体同属一方协同攻击，差额取哪一侧请确认。
8. **移动范围是否含 royroy 自身机动**：royroy 是独立部署单位，其移动范围按其自身机动算（不进机体移动范围）。请确认。
9. **机动值差额下限**：规则只说 >+5 封顶 5，未提下限；默认差额可为负、不封底。请确认是否需要下限（如 −5）。
