## 一、现状结论

技能系统已完成 v5 万能语法重构：`skillExecutor.cjs` 只认 `action_type`（attack/heal/buff/debuff/passive）5 谓语 switch，不认技能名；词条 = JSON 配置驱动。未知 action_type 落 default 静默失效（仅返回 bonus_value）。

**关键架构事实（代码实测，纠正旧记忆）**：
- `executeAssist/executeGuard/executeBlockade` 已在 v5 重构中**彻底废弃**，改用 `statusEffects + matchTrigger` 动态提取（见 `skillExecutor.cjs:283/972`、`skillRegistry.cjs:34`）。
- `conditionTrigger.cjs` 已实现并被 `buffManager.cjs:335` 实际调用；`damagePipe.cjs:101–110` 用 `BuffManager.getMatchingStatus(..., 'attack'/'attack_debuff_target'/'defense')` + `matchTrigger` 在结算时动态提取状态效果（assist 增伤 / guard 减伤 / blockade 削机动）。**条件触发已接入伤害管道**。
- `/skill` 路由（`combat.ts:874–878`）已写回 `casterUnit.statusEffects` 与 `targetUnit.statusEffects`。
