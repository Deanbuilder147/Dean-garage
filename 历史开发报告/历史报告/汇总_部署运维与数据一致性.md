## 一、现状结论

### 1. Nginx API 代理（已修复并部署 2026-07-27）
- 根因：地形上传 `POST /api/terrain/upload` 线上 405，因 nginx 缺 `/api/terrain/` 块，兜底 `location /` 把 POST 当静态文件。
- 同源隐患：GET 漏配会返回 `index.html` 源码 + 200 OK → 前端 `Unexpected token '<'` JSON 崩溃/裂图。
- **实测漏配**：`/api/terrain/`（已报）+ `/api/asset-gen/`（新发现，前端 `AssetGenPanel.vue` 已用）。
- **修复**：`frontend/nginx.conf` 删除全部零散 `/api/xxx/` 块与 4 个死配置块，替换为单个 `location /api/ { proxy_pass http://mecha-gateway:3006; }`（无尾斜杠保留前缀）；新增 `location /api/debug/ { deny all; }`。
- 验证全绿：`nginx -t` ok；`/api/terrain/upload` 现 401（直达后端）；`/api/asset-gen/credits` 现 401+JSON；debug 403；`/api/map/list` 回归 200。

### 2. 地形数据一致性
- 多源地形成本/颜色/素材已统一对齐，详见《地形与六边形渲染改造》汇总。

### 3. Meowa / AI 素材生成适配
- `asset-gen` 模块（上传参考图 → Meowa 生成）前端已接入；nginx 漏配修复后该模块线上可用。

## 二、部署铁律（重要）
- nginx.conf 是**构建期 COPY** 进前端镜像，**改后必须 `docker compose build --no-cache mecha-frontend`**，光 `npm run build` 无效。
- 前端 dist 仅服务器 `npm run build` 产出（Dockerfile 只 COPY dist），rsync 又 exclude dist → 改源码需服务器 build 后再 build 镜像。
- 绝不动 `mecha-battle-db` 容器。
