## 8. 战斗视图 BattleView

```
┌─────────────────────────────────────────────────────┐
│  第 N 回合 | 当前阵营 | [退出战斗]     (顶部状态栏)  │
├─────────────────────────────────────────────────────┤
│                                                     │
│                                                     │
│                 【战斗画布区域】                      │
│            (六角格地图 + 单位 + 动画)                 │
│                   PixiJS Canvas                     │
│                                                     │
│                                                     │
├─────────────────────────────────────────────────────┤
│  【侧边栏】(根据阶段显示不同内容)                      │
│                                                     │
│  阶段1: 出生点选择                                    │
│  ├─ 当前选择玩家显示                                  │
│  ├─ 选择顺序列表                                     │
│  └─ 点击地图母舰/基地选择                             │
│                                                     │
│  阶段2: 单位部署                                      │
│  ├─ 我的出生点显示                                   │
│  ├─ 待部署单位列表                                   │
│  └─ 拖拽部署操作                                     │
│                                                     │
│  阶段3: 回合行动                                      │
│  ├─ 当前行动玩家                                     │
│  ├─ 已行动单位 / 待行动单位                          │
│  ├─ [选择单位] [移动] [攻击] [技能]                  │
│  └─ 动作日志                                         │
│                                                     │
│  阶段4: 回合结束                                      │
│  └─ 回合总结、战果统计                               │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**主要元素：**
- 顶部状态栏（回合数、当前阵营、退出按钮）
- 主战斗画布（PixiJS 渲染的六角格战场）
- 侧边栏（多阶段UI）：
  - 出生点选择阶段
  - 单位部署阶段
  - 回合行动阶段（选择单位、移动、攻击、技能）
  - 回合结束阶段
- 实时战况日志

## 技术说明

- **前端框架**: Vue 3 + Vite
- **画布渲染**: PixiJS (战斗地图)
- **UI组件**: 自定义组件库 (UIButton, UIModal, Icon等)
- **通信**: Socket.io (实时对战)
- **状态管理**: Pinia (本地状态)
