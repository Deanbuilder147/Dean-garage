## 五、关键数据结构

### 5.1 大一统词元枚举 (LexicalToken)

```typescript
enum LexicalToken {
  SELF, TARGET,             // 主语/宾语
  MOVE_ACTION,              // 移动动作
  DAMAGE_PHYSICAL,          // 物理伤害
  DAMAGE_ENERGY,            // 能量伤害
  DICE_ROLL,                // 骰子检定
  CONSUME,                  // 资源消耗
  BUFF,                     // 增益/减益
}
```

### 5.2 定状补句式结构 (OrderClause)

```typescript
interface OrderClause {
  name: string;             // 句式名称
  predicate: LexicalTokenValue;  // 谓语词元
  qualifiers: Qualifier[];  // 定语：前置代价卡口
  adverbials: Adverbial[];  // 状语：运行时投骰
  complements: Complement[];// 补语：数值累加
  meta?: Record<string, unknown>;
}

// Qualifier = { tag, subject:'SELF'|'TARGET', field, operator, value, failMessage }
// Adverbial = { diceExpression, successLine, failValue, label }
// Complement = { mode:'flat'|'percent'|'dice_bonus', value, targetField, label }
```

### 5.3 实体矩阵 (EntityMatrix)

```typescript
interface EntityMatrix {
  id: string;
  is_public_copy: boolean;       // 版权溯源
  original_author_id: string;    // 原作者
  generation_status: GenerationStatus;  // AI 形象状态
  attributes: Map<string, unknown>;     // KV 动态容器
  name, faction, category, tier: string | number;
  sprite_key: string;
  stats: UnitStats;              // 8 维属性：hp/maxHp/armor/shield/attack/defense/speed/range
  skills: UnitSkill[];           // 技能列表（含 DSL 脚本）
  created_by, created_at, updated_at;
}
```

### 5.4 战斗运行时 (BattleState)

```typescript
interface BattleState {
  id: string;
  phase: BattlePhase;            // DEPLOYMENT→INITIATIVE→MOVEMENT→COMBAT→RESOLUTION→CLEANUP
  turn: number;
  activeUnitId: string;
  units: Map<string, BattleUnit>;
  map: BattlefieldMap;
  log: BattleLogEntry[];
  startedAt: string;
}

interface BattleUnit {
  unitId, matrixId, ownerId: string;
  position: HexCoord;            // { q: number, r: number }
  currentStats: UnitStats;
  skills: UnitSkill[];
  statusEffects: StatusEffect[];
  hasMoved, hasAttacked: boolean;
}
```

### 5.5 六角格坐标系统

```
Even-R Offset（尖顶，双数行右移半格）
  HEX_WIDTH=64, HEX_HEIGHT=72, HEX_RADIUS=36

坐标转换链（宪法红线）：
  hexToPixel(q,r) → pointyTopCenter → {flatX, flatY}
  2D → 等距: flatToIso(flatX, flatY, camX, camY, height) → {isoX, isoY}
  等距 → 2D: isoToFlat(isoX, isoY, camX, camY) → {flatX, flatY}
  2D → hex: pointyTopToHex(flatX, flatY, size, spacingH, spacingV) → {q, r}
```

## 六、数据流路径

### 6.1 认证流

```
用户输入 → NewLoginView → authAPI.login(username, password)
  → Nginx reverse proxy → /api/auth/ → mecha-gateway:3006
  → JWT 签发 → { token, user }
  → localStorage.setItem('token') + useUserStore.setUser()
  → 路由守卫放行 → /home
```

### 6.2 单位管理流

```
NewUnitEditorView → hangarAPI.createUnit(formData)
  → Nginx → /api/hangar/ → mecha-hangar:3002
  → SQLite 持久化 → 返回 EntityMatrix
  → 前端更新单位列表
```

### 6.3 地图编辑流

```
NewBattlefieldView → HexGridCanvasEngine 渲染网格
  → 用户点击涂色 → terrain cells Map 更新
  → mapAPI.createBattlefield(cells) → mecha-map:3003
  → SQLite 存储 → 返回 BattlefieldMap
```

### 6.4 战斗数据流（全链路）

```
整备室 (PreparationRoom)
  → onlineBattleAPI.startBattle(roomId)
  → combatAPI.createBattle({ mapId, units })
  → combatAPI.deployUnit / endDeployment
  → 进入 NewBattleView

战场循环 (NewBattleView):
  Canvas 点击 → HexGridCanvasEngine @cell-clicked → onHexClick(q, r)
    → 移动: combatAPI.move(id, { from, to }) → 寻路校验 → 更新 BattleState
    → 攻击: combatAPI.attack(id, { from, to }) → damagePipe 算伤 → 骰子动画 → 更新 HP
    → 结束回合: combatAPI.endTurn(id) → 切换 activeUnitId

  算伤管道 (damagePipe.ts, 服务端):
    攻击指令 → 拉取 OrderClause 规则 JSON
    → 定语(qualifiers): 代价检查（hasMoved、HP阈值、状态效果）
    → 状语(adverbials): 骰子判定（dicescript 1d6/successLine）
    → 补语(complements): 层叠累加（flat → percent → dice_bonus）
    → 防具减伤计算 → 最终伤害

  实时同步:
    Socket.io ← comm-service:3005 → 广播 BattleLogEntry
    → 前端更新 unitSprites → Canvas 重绘
```

### 6.5 词条库同步流

```
GlossaryView → glossaryAPI.getConfig()
  → Nginx → /api/combat/glossary-config → mecha-gateway:3006 → proxy → mecha-combat:3004
  → 返回技能规则 JSON → 编辑器展示

用户编辑保存 → glossaryAPI.saveConfig(config)
  → combat-service 热更新技能规则缓存
  → 战场技能计算即时生效
```

### 6.6 Canvas 渲染管道（宪法红线）

```
父组件 (NewBattleView / NewBattlefieldView)
  → 生成 gridData: { gridWidth, gridHeight, terrainCells[], spacingH, spacingV, ... }
  → HexGridCanvasEngine.props.gridData
  → Engine 内部：
      1. 计算 Canvas 逻辑尺寸（硬编码，非 CSS Flex）
      2. 遍历可见单元格 → pointyTopCenter(q, r) → flatToIso() → drawHexPath()
      3. 地形离屏缓存（useTerrainCache=true）
      4. 调用 drawFn(ctx) 委托父层绘制单位/特效
      5. requestAnimationFrame 16 帧时钟循环
  → 鼠标点击：逆变换 isoToFlat → pointyTopToHex → emit cell-clicked(q, r)
  → 父层接收纯坐标，执行业务逻辑（部署/移动/攻击）
```
