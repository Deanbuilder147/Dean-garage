### 2.1 属性字段三国演义

同一组属性在不同服务中有 **3 套完全不同** 的命名：

| 属性含义 | Hangar DB (SQLite) | Combat DB (PG/SQLite) | Code (unitConverter) | 前端显示 |
|----------|--------------------|------------------------|----------------------|----------|
| 格斗（近战） | `main_格斗` | `ge_dou` | `melee` | "格斗" / "近战" |
| 射击（远程） | `main_射击` | `she_ji` | `ranged` | "射击" / "远程" |
| 结构（防御） | `main_结构` | `jie_gou`(隐含) | `defense` / `structure` | "防御" |
| 机动（速度） | `main_机动` | `ji_dong` | `mobility` | "机动" |
| 生命值 | `hp`(推导) | `hp` | `hp` / `max_hp` | "HP" |

### 2.2 装备字段

Hangar DB 用中文前缀：
```
left_格斗, left_射击, left_结构, left_机动
right_格斗, right_射击, right_结构, right_机动
```

Combat DB 用英文：
```
left_hand_melee, left_hand_ranged, left_hand_defense, left_hand_durability
right_hand_melee, right_hand_ranged, right_hand_defense, right_hand_durability
```

unitConverter.js 在中间做桥接（行 49-52, 182-184）。

**建议：** 不改数据库 schema（成本太高），但在 API 层统一输出英文名，由 unitConverter 承担转换。

### 3.3 战斗属性

| 含义 | 统一中文 | 统一代码 | 当前重名/混用情况 |
|------|---------|---------|------------------|
| 近战攻击 | **格斗** | `melee` | 也叫"近战" |
| 远程攻击 | **射击** | `ranged` | 也叫"远程" |
| 防御力 | **结构** | `defense` | 也叫"防御"、"护甲" |
| 移动力 | **机动** | `mobility` | 也叫"速度" |
| 生命值 | **结构值**（详见下方说明） | `hp` | 也叫"生命"、"血量"、"HP" |
| 耐久度 | **结构值**（武器/载具限定） | `durability` | 武器或载具的可使用次数 |

> **结构值的双重语义：** 「结构值」是单位的通用基础属性，但根据单位类型不同，其含义会转换：
> - **机体 / RoyRoy / 防具 / 背包**：结构值按比例转换成 **HP（生命值）**，决定单位能承受多少伤害。
> - **武器 / 载具**：结构值转换为 **耐久度**，即该装备/载具的 **可使用次数**，每次使用消耗 1 点耐久，耐久归零时该装备/载具失效。
| 射程 | **射程** | `range` | 也叫"范围" |
| 攻击力 | **攻击** | `attack` | 一致 |

| 被动技能 / 自动化技能 / auto | **自动化技能**（UI）/ **auto_skill**（代码） |

#### 技能范围与效果规则

1. **技能类型决定攻击范围与特殊效果**：不同技能根据其技能类型（近战型 / 远程型 / 特殊型等）拥有不同的攻击范围模板和附加特殊效果。
2. **非机体/RoyRoy 单位的攻击力计算**：如果使用技能的单位类型不是「机体」或「RoyRoy」（例如武器类单位单独使用技能），则攻击力需 **加上该单位自身的格斗值（对应近战技能）或射击值（对应远程技能）** 再进行伤害计算。

### 3.7 战斗流程

战斗流程的层级关系如下（从大到小）：

```
轮次（Round）
  └── 阵营回合（Faction Turn）  ← 场上所有阵营按顺序各执行一轮
        └── 单位回合（Unit Turn）  ← 阵营内各单位依次行动
              ├── 移动阶段（Movement Phase）  ← 单位回合中的移动行动
              └── 战术阶段（Tactical Phase）  ← 单位回合中的战术行动
```

| 术语 | 统一中文 | 统一代码 | 定义 |
|------|---------|---------|------|
| Round | **轮次** | `round` | 场上所有阵营按顺序各自完成一个「阵营回合」，称为一个轮次 |
| Faction Turn | **阵营回合** | `faction_turn` | 一个阵营内所有单位依次行动完毕 |
| Unit Turn | **单位回合** | `unit_turn` | 单个作战单位的一次完整行动机会 |
| Movement Phase | **移动阶段** | `movement_phase` | 单位回合中执行移动行动的阶段 |
| Tactical Phase | **战术阶段** | `tactical_phase` | 单位回合中执行战术行动（攻击、技能等）的阶段 |
| Action | **行动** | `action` / `has_acted` | 单位是否已执行过行动 |

> **注：** 阵营行动顺序按阵营顺序依次进行，具体顺序可能需在后续战场系统中调整。

## 八、更新记录

### 2026-06-14 v2 — 游戏机制术语细化

**1. 结构值双重语义（更新 §3.3、§七）**
- 结构值在「机体 / RoyRoy / 防具 / 背包」类型下 → 按比例转换为 **HP（生命值）**
- 结构值在「武器 / 载具」类型下 → 转换为 **耐久度（可使用次数）**
- 耐久度归零 = 装备/载具失效

**2. 技能攻击力补充规则（新增 §3.5 子节）**
- 技能类型决定攻击范围模板和特殊效果
- 非机体 / 非 RoyRoy 单位使用技能时，攻击力需追加该单位自身的 **格斗值（近战技能）** 或 **射击值（远程技能）**

**3. 战斗流程层级重构（重写 §3.7、更新 §七）**
- 旧称：「回合」「阶段」「行动」三层，存在「回合」与「轮次」概念混淆
- 新层级：
  - **轮次（Round）** = 所有阵营各完成一个阵营回合
  - **阵营回合（Faction Turn）** = 一个阵营内全部单位行动完毕
  - **单位回合（Unit Turn）** = 单个单位的完整行动
  - **移动阶段（Movement Phase）** = 单位回合中的移动行动
  - **战术阶段（Tactical Phase）** = 单位回合中的战术行动
- 阵营按顺序依次行动（后续战场系统可能调整）

**变更影响范围：** 仅文档术语定义更新，不涉及代码或数据库修改。后续在编写战斗核心逻辑时需按此层级命名。
