## 二、战前阶段

### 2.1 登录/注册

- 入口：`TerminalView` 终端界面

### 2.2 主页 (HomeView)

三个功能入口：

| 入口 | 路径 | 功能 |
|------|------|------|
| 机甲棋库 | `/units` | 创建/编辑棋子 |
| 整备室 | `/preparation/:roomId` | 阵容编组、部署 |
| 开始对战 | `/battle/:id` | 进入回合制对战 |

### 2.3 机甲棋库（棋子创建）

创建棋子时设置的属性：

| 属性 | 说明 | 对应战斗属性 |
|------|------|-------------|
| 格斗 | 近战攻击力 | → `attack` |
| 射击 | 远程攻击力 | → `attack` |
| 结构 | 机体强度 | → `defense` / `HP` |
| 机动 | 移动能力 | → `mobility` |
| 左手装备 | 武器/护盾/推进器 | → weaponType / shield |
| 右手装备 | 武器/护盾/推进器 | → weaponType / shield |
| 额外装备 | 导弹/特殊武器 | → special weapon |

装备类型映射：

| 中文类型 | 英文战斗类型 |
|----------|-------------|
| 光束剑 | beam |
| 实弹步枪 | kinetic |
| 导弹发射器 | missile |
| 能量炮 | energy |
| 护盾 | shield |
| 推进器 | booster |

- 路径：`/battlefields`

## 三、整备室流程

路径：`/preparation/:roomId`

```
1. 进入房间
   ↓
2. 选择阵营（地球联合 / 马克西翁 / 拜隆 / 中立）
   ↓
3. 配置 AI 对战设置（PvP 或 PvE）
   ↓
4. 编组阵容 —— 从棋库中选择棋子加入阵容
   ↓
5. 在战场上布置初始位置
   ↓
6. 准备就绪 → 开始对战
```

## 四、战斗阶段

### 4.1 战斗界面布局（DM 控制台模式）

```
┌──────────────┬──────────────────────┬──────────────┐
│  左侧边栏     │      战场画布         │  右侧行动面板  │
│              │                      │              │
│  · DM控制台   │    [六角格地图]       │  单位信息     │
│  · 导航菜单   │                      │  · HP/护盾    │
│  · 行动记录   │    PixiJS 渲染       │  · 攻击/防御   │
│   (半透明)    │                      │  · 机动/射程   │
│              │                      │              │
│              ├──────────────────────┤  [移动]      │
│              │    阵营分框           │  [攻击]      │
│              │ [地球联合][马克西翁]   │  [防御]      │
│              │ [Unit][Unit]...      │  [技能]      │
│              │                      │  [待机]      │
└──────────────┴──────────────────────┴──────────────┘
```

### 4.2 部署阶段

1. DM 在底部阵营框中查看可用单位
2. 未部署单位旁显示「部署」按钮
3. 点击部署后选择战场上的放置位置
4. 所有单位部署完毕后，点击「完成部署」→ 进入回合制对战

部署时初始化的战斗属性：

```javascript
{
  hp: 100, max_hp: 100,
  attack: 12, defense: 6, mobility: 3,
  weaponType: 'beam', armorType: 'normal',
  shield: 0, level: 1,
  has_moved: false, has_acted: false,
  royroy_deployed: false,
  buffs: []
}
```

### 4.3 回合制流程

1. DM 点击战场上的棋子 → 选中（白色虚线高亮）
2. 右侧行动面板显示单位详情和可用行动
3. 选择行动（移动/攻击/防御/技能/待机）
4. 执行行动，侧边栏记录操作
5. 该阵营所有单位行动完毕后，点击「结束回合」
6. 切换至对方阵营

## 五、回合内流程 (executeTurn)

> 来源：`services/combat-service/src/services/combatResolver.js`

每次执行攻击时，按以下顺序处理：

```
                    ┌──────────────┐
                    │  开始回合/攻击  │
                    └──────┬───────┘
                           ↓
              ┌────────────────────────┐
              │ 1. 迷雾判定             │
              │    1d6 三段判定          │
              │    1-2: 完全不可见(-50%) │
              │    3-4: 部分可见(-25%)  │
              │    5-6: 正常             │
              └────────────┬───────────┘
                           ↓
              ┌────────────────────────┐
              │ 2. 奇袭判定（仅第一回合）  │
              │    1d6 >3 → 奇袭失败    │
              │    成功 → 70%先手伤害    │
              └────────────┬───────────┘
                           ↓
              ┌────────────────────────┐
              │ 3. 导弹轰炸（如有导弹武器）│
              │    发射 3 枚导弹        │
              │    每枚 1d6 独立判定    │
              │    ≥4 命中 (50%命中率)  │
              │    每枚 40% 攻击力伤害   │
              └────────────┬───────────┘
                           ↓
              ┌────────────────────────┐
              │ 4. 主攻击               │
              │    调用 DamagePipe      │
              │    9阶段伤害计算管道     │
              └────────────┬───────────┘
                           ↓
                    ┌──────────────┐
                    │  伤害结算完成   │
                    └──────────────┘
```

## 六、伤害计算管道 (DamagePipe)

> 来源：`services/combat-service/src/services/combatCore/damagePipe.cjs`

### 核心常量

| 常量 | 值 | 说明 |
|------|---|------|
| CRIT_THRESHOLD | 5 | 暴击阈值：1d6 ≥ 5（33% 概率） |
| CRIT_MULTIPLIER | 1.5 | 暴击倍率 |
| GUARANTEED_DAMAGE | 1 | 保底伤害 |

### 武器克制矩阵

| 武器类型 | vs 普通装甲 | vs 重型装甲 | vs 护盾 |
|----------|:----------:|:----------:|:------:|
| beam (光束) | 1.0 | 1.3 | 0.7 |
| kinetic (实弹) | 1.0 | 0.8 | 1.2 |
| missile (导弹) | 1.0 | 1.1 | 0.9 |
| energy (能量) | 1.0 | 1.2 | 0.8 |

### 9 阶段计算流程

| 阶段 | 名称 | 公式 | 说明 |
|:----:|------|------|------|
| 0 | 迷雾命中判定 | `1d6` → 1-2 miss, 3-4 部分, 5-6 正常 | 先判定是否因迷雾 miss |
| 1 | 基础攻击力 | `attacker.attack \|\| 10` | 取攻击者攻击力 |
| 2 | 机动性加成 | `floor(mobility * 0.3)` | 机动性的 30% 转为攻击加成 |
| 3 | 武器类型克制 | 查克制矩阵 | 根据 weaponType vs armorType |
| 4 | 攻击 Buff | Σ 所有攻击类 buff | 求和所有攻击增益 |
| 5 | 临时攻击力 | `1 + 2 + 3 + 4` | 阶段 1~4 之和 |
| 6 | 等级差修正 | `1 + (atkLv - defLv) * 0.05` | 每级差 ±5% |
| 7 | 暴击判定 | `1d6 >= 5 → *1.5` | 33% 概率 1.5x 暴击 |
| 8 | 防御减免 | `defense + shield + terrainDef + buffs` | 光束武器对护盾 1.5x 有效 |
| 9 | 最终伤害 | `max(1, floor(damage - defense))` | 保底 1 点伤害 |

## 七、骰子系统 (DiceEngine)

> 来源：`services/combat-service/src/services/combatCore/DiceEngine.cjs`

基于**海豹骰子 dicescript**（用 GopherJS 编译 dicescript.js VM），所有判定统一使用 **1d6**。

| 方法 | 功能 | 用途 |
|------|------|------|
| `roll(formula)` | 执行骰子表达式，返回数值 | 基础掷骰 |
| `rollDetails(formula)` | 返回每个骰子的具体点数 | 调试/展示 |
| `check(formula, op, threshold)` | 掷骰并判断是否满足条件 | 阈值判定 |
| `rollMultiple(formula, count)` | 批量掷骰 | 多发判定 |
| `reset()` | 重置 VM 状态 | 新回合换种子 |

### 各系统的骰子使用

| 系统 | 原先骰子 | 统一后 | 判定规则 |
|------|:------:|:------:|------|
| 奇袭 | 1d10 | **1d6** | >3 失败 |
| 迷雾 | 1d6 | **1d6** | 1-2: -50%, 3-4: -25%, 5-6: 正常 |
| 导弹轰炸 | 1d10×3 | **1d6×3** | ≥4 命中 (50%) |
| 暴击 | 1d6 | **1d6** | ≥5 (33%) |
| 冲锋攻击 | 1d6 | **1d6** | ≥3 成功，机动×0.5 额外伤害 |

## 八、特殊战斗系统

### 8.1 奇袭系统 (Ambush)

- **触发**：仅第一回合
- **判定**：`1d6 > 3` → 奇袭失败（50% 触发率）
- **效果**：成功时造成 **70% 基础攻击力**的先手伤害

### 8.2 导弹轰炸 (Missile Barrage)

- **触发**：攻击方配有导弹武器时
- **判定**：发射 3 枚导弹，每枚 `1d6` 独立判定
- **命中**：`≥4` 命中（50% 命中率）
- **伤害**：每枚造成 **40% 攻击力**伤害
- **目标**：随机选择敌方单位

### 8.3 迷雾系统 (Fog of War)

- **判定**：`1d6` 三段判定
  - `1-2`：完全不可见 → 命中率 -50%
  - `3-4`：部分可见 → 命中率 -25%
  - `5-6`：正常 → 无影响

### 8.4 冲锋攻击 (Charge Attack)

- **判定**：`1d6 ≥ 3` 成功
- **效果**：机动性 × 0.5 转为额外伤害

### 8.5 反击 (Counter Attack)

- **触发**：受击后
- **效果**：以 **60% 攻击力**回击

### 8.6 穿透攻击 (Phase Attack)

- **效果**：忽略 **50%** 防御力和护盾
