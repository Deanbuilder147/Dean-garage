### 页面 1：终端登录页 `TerminalView`

**路由** `/`  
**权限** 无需登录（已登录自动跳转 `/home`）  
**后端 API** `POST /api/auth/login` `POST /api/auth/register`

#### 功能清单

| 功能 | 说明 |
|------|------|
| 终端风格启动动画 | 模拟命令行系统引导（boot sequence） |
| 命令行登录 | 输入 `login` → 用户名 → 密码，调用 `POST /api/auth/login` |
| 命令行注册 | 输入 `register` → 用户名 → 密码，调用 `POST /api/auth/register` |
| 输入 `sim_combat` 进入主页 | 登录成功后跳转 `/home` |
| 自动跳转 | 已登录用户（有 token）自动跳转 `/home` |
| 错误提示 | 登录/注册失败时显示终端风格错误信息 |

### 页面 5：棋子管理页 `NewUnitEditorView`

**路由** `/units` `/units/new` `/units/:id`  
**权限** 需登录  
**后端 API** `GET/POST/PUT/DELETE /api/hangar/` `GET /api/hangar/unit-types`  
**后端 API** `POST /api/hangar/import-excel` `POST /api/hangar/parse-excel` `POST /api/hangar/create-from-json` `POST /api/hangar/upload-image`

#### 三种模式

| 模式 | 路由 | 说明 |
|------|------|------|
| 列表模式 | `/units` | 查看所有棋子 |
| 创建模式 | `/units/new` | 新建棋子 |
| 编辑模式 | `/units/:id` | 编辑已有棋子 |

#### 列表模式功能

| 功能 | 说明 |
|------|------|
| 棋子列表 | 卡片或表格展示所有棋子，调用 `GET /api/hangar/` |
| 棋子筛选 | 按阵营(faction)、类型筛选 |
| 棋子搜索 | 按名称搜索 |
| 新建棋子 | 按钮 → 跳转 `/units/new` |
| 编辑棋子 | 点击棋子 → 跳转 `/units/:id` |
| 删除棋子 | 确认弹窗后调用 `DELETE /api/hangar/:id` |

#### 创建/编辑模式功能

| 功能 | 说明 |
|------|------|
| 基本信息表单 | 名称、代号、阵营 |
| 主机体属性 | 类型、格斗、射击、结构、机动、技能 |
| 左手武器 | 类型、属性、技能 |
| 右手武器 | 类型、属性、技能 |
| 其他装备 | 类型、属性、技能 |
| 跟随单位 | RoyRoy 启用开关、属性、技能 |
| 图片上传 | `POST /api/hangar/upload-image` |
| Excel 导入 | 上传 Excel 文件 → `POST /api/hangar/import-excel` |
| JSON 创建 | `POST /api/hangar/create-from-json` |
| 保存 | `POST /api/hangar/` 或 `PUT /api/hangar/:id` |

### 页面 7：战场编辑器 `NewBattlefieldView`

**路由** `/battlefield-edit` `?id=xxx`  
**权限** 需登录  
**后端 API** `GET/POST/PUT/DELETE /api/map/` `GET /api/map/terrain/types`  
**后端 API** `POST/DELETE /api/map/:id/terrain` `POST /api/map/utils/path` `POST /api/map/utils/range`

#### 功能清单

| 功能 | 说明 |
|------|------|
| 六角格画布 | 交互式六角格战场编辑器 |
| 战场基本信息 | 名称、尺寸（宽×高）、描述 |
| 地形类型管理 | 调用 `GET /api/map/terrain/types` 获取可用地形 |
| 放置地形 | 点击六角格 → 选择地形类型 → `POST /api/map/:id/terrain` |
| 移除地形 | 点击已放置地形 → 删除 → `DELETE /api/map/:id/terrain` |
| 自定义地形类型 | CRUD 地形类型 `POST/PUT/DELETE /api/map/terrain/types` |
| 出生点设置 | 在格子上标记玩家出生点 |
| 寻路预览 | 点击两个格子 → `POST /api/map/utils/path` → 高亮路径 |
| 攻击范围预览 | 点击格子 → `POST /api/map/utils/range` → 高亮范围 |
| 保存战场 | `POST /api/map/` 或 `PUT /api/map/:id` |
| 缩放/平移 | 画布拖拽和缩放 |

### 页面 9：对战界面 `NewBattleView`

**路由** `/battle/:id`  
**权限** 需登录  
**后端 API** 通过 WebSocket (`/socket.io/`) 实时通信  
**后端 API** `POST /api/combat/` 战斗计算（通过 comm-service 中转）

#### 功能清单

| 功能 | 说明 |
|------|------|
| 战场渲染 | PixiJS 渲染六角格战场、棋子、地形 |
| 回合制战斗 | 轮流行动：移动 → 攻击 → 结束回合 |
| 棋子移动 | 点击棋子 → 显示可移动范围 → 点击目标格子移动 |
| 攻击系统 | 选择目标 → 计算伤害（经过 DamagePipe 管道） |
| 战斗动画 | 移动动画、攻击动画、伤害数字弹出 |
| 伤害计算管道 | 9 阶段计算：基础攻击→机动加成→武器克制→Buff→等级差→暴击→防御减免→最终伤害 |
| 奇袭系统 | 第一回合判定 1d6>3，触发奇袭伤害 |
| 导弹轰炸 | 3 枚导弹独立判定 1d6>=4 命中 |
| 迷雾系统 | 1d6 决定 visibility：blind/partial/normal |
| 行动日志 | 实时显示每回合的行动记录 |
| 棋子状态面板 | 选中棋子显示 HP、攻击力、防御力、技能等 |
| 回合指示器 | 显示当前回合数和当前行动方 |
| 胜利条件判定 | 一方全灭或达成胜利条件 |
| 战斗结束 | 显示胜负结果、统计数据 |
| 返回大厅 | 按钮 → 返回 `/lobby` 或 `/home` |
