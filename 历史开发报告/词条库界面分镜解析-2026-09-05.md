## 0. 实现约束（重要）

- 后续前端实现须**直接使用 SVG 分镜中已命名的组件 / 分组**，尽量不自行发明组件。SVG 内的 `<g id="...">` 分组名即界面组件的权威来源（见第 6 节组件清单）。
- **「镜头」与「画面」的区别（已确认·关键）**：整张 SVG = **一整张「词条库大页面」**；三个镜头（`镜头1_词条类型_` / `镜头2_词条选择_` / `镜头3_词条编辑_`）是三台**相机取景框**，分别对准这张大页面的不同部位（左=词条类型区 / 中=词条选择区 / 右=词条编辑区）。**切换镜头 = 平移相机查看同一张页面的不同部位**，不是切换三个独立页面。红/绿/蓝框仅为镜头标注（区分取景），界面不显示。
- 本质：对现有 `GlossaryStudio` 的**重设计**；目标用户 = **玩家**（查看 + 编辑）。
- 结构：大页面横向平铺三段，每段约 1220×783；镜头用 `viewBox` 取景（平移/缩放），保留到最终 UI。

## 4. 镜头 3《词条编辑》（`镜头3_词条编辑_`）

| 栏 | 边界 | SVG 组件 | 内容 |
|----|------|----------|------|
| 左栏 | 蓝框 | （词条分类导航 / 列表复用） | 分类或词条切换 |
| 中栏 | 红框 | `棱镜` / `宝石嵌入` | 词条可视化画布（棱镜/宝石主题） |
| 右栏 | 绿框 | `when` / `if` / `roll` / `do` / `effect` / `cost`（六段式原子）<br>`详细排列`（标题，两侧箭头可切换段落）<br>`词条明细` / `提示栏` / `词条明细-2` / `提示栏-2` / `提示栏-3`（矩形卡片） | ① 六段组件 = **六段式** WHEN/IF/ROLL/DO/AFTER/COST（effect = AFTER 后效，已确认）<br>② `详细排列` 标题 + 段落切换箭头<br>③ 矩形卡片 = **词条基础属性卡**（填非六段式属性） |

- **六段对应（已确认）**：右栏 6 个组件名即六段，且**组成右侧「六条形」**（六段导航/状态条），**从左往右**依次 = `when`(WHEN) / `if`(IF) / `roll`(ROLL) / `do`(DO) / `effect`(AFTER 后效) / `cost`(COST)。点击某一条可定位/选中该段。
- **「编辑段落」大框（`详细排列`，已确认）**：六条形下方一整段大框（标题 + 两侧箭头切换段落）= **编辑区**，可在其中选择并编辑单独某一段（其原子/字段）。即：六条形负责选段导航，编辑段落大框负责编辑该段内容。
- **基础属性卡（已确认）**：`词条明细`/`提示栏`/`词条明细-2`/`提示栏-2`/`提示栏-3` 矩形卡片 = 填写不在六段式内的词条基础属性，目前仅 **「近战 / 远程 / 自动化」三项**（词条形态切换，单选项/多选项待确认）。
