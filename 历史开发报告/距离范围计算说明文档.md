## 一、六角格坐标系统

### 1.1 Offset 坐标 (q, r)

棋盘使用 offset 坐标系（奇数行偏移），每个格子由 `(q, r)` 标识。

```
     (0,0) (1,0) (2,0) (3,0) (4,0)
        (0,1) (1,1) (2,1) (3,1) (4,1)
     (0,2) (1,2) (2,2) (3,2) (4,2)
        (0,3) (1,3) (2,3) (3,3) (4,3)
```

**六邻格方向** (offset)：
| 方向 | dq | dr |
|:-----|:--|:--|
| 右下 | +1 | +0 |
| 右上 | +1 | -1 |
| 上   |  0 | -1 |
| 左上 | -1 | +0 |
| 左下 | -1 | +1 |
| 下   |  0 | +1 |

### 1.2 Cube 坐标 (x, y, z)

从 offset → cube 转换：
```
x = q - (r - (r & 1)) / 2
z = r
y = -x - z
```

Cube 坐标满足恒等式：`x + y + z = 0`

## 二、距离计算公式

### 2.1 hexDistance —— 六角格距离

**定义**（前端 `hex-skill-range-map.html`）：
```javascript
function hexDistance(q1, r1, q2, r2) {
  const a = offsetToCube(q1, r1);
  const b = offsetToCube(q2, r2);
  return Math.max(Math.abs(a.x - b.x), Math.abs(a.y - b.y), Math.abs(a.z - b.z));
}
```

**定义**（后端 `skillExecutor.cjs`）：
```javascript
_hexDistance(a, b) {
    if (!a || !b) return 999;
    const dq = Math.abs((a.q || 0) - (b.q || 0));
    const dr = Math.abs((a.r || 0) - (b.r || 0));
    const ds = Math.abs(((a.q || 0) - (b.q || 0)) + ((a.r || 0) - (b.r || 0)));
    return Math.max(dq, dr, ds);
}
```

> **注意**：前端使用 cube 坐标转换计算，后端直接使用 offset 坐标的曼哈顿变形公式。两者在 offset 坐标系（奇数行偏移）下**等价**。

### 2.2 距离层与格子数

| 距离 (d) | 格子数 | 说明 |
|:---------|:------|:-----|
| 0 | 1 | 中心格自身 |
| 1 | 6 | 相邻六角格（一圈） |
| 2 | 12 | 第二圈 |
| 3 | 18 | 第三圈 |
| ... | 6×d | 第 d 圈 |

累计格子数：距离 ≤ d 的格子总数 = 1 + 3d(d+1)

## 三、技能距离范围定义

### 3.1 近战技能

#### 普通近战 / 反击 / 格挡 → 1-1

| 属性 | 值 |
|:-----|:---|
| 最小距离 | 1 |
| 最大距离 | 1 |
| 判定公式 | `hexDistance = 1` |
| 格子数 | 6 格（相邻六角格） |
| 是否含自身 | ❌ 否 |

**实现**：
- 前端：`getMeleeRange(oq, or)` — 遍历 `HEX_DIRS` 6 个方向
- 后端：`executeCounter()` — `dist !== 1 && dist > skillRange` 双重检查
- 后端：`executeSupply()` — `dist > 1 || dist === 0` 双重检查

**示例**（单位在 J10）：
```
J10 为中心格
1-1 范围：I9, J9, K9, I10, J11, K11  ← 6 格
```

#### 长柄 → 1-2

| 属性 | 值 |
|:-----|:---|
| 最小距离 | 1 |
| 最大距离 | 2 |
| 判定公式 | `1 ≤ hexDistance ≤ 2` |
| 格子数 | 6 + 12 = 18 格 |
| 是否含自身 | ❌ 否 |

**实现**：
- 前端：`getPolearmRange(oq, or)` = `getRadiusRange(oq, or, 2, 1)`
- 后端：`getPolearmExtraRange()` — 统一返回 `1`（在基础近战 1 上 +1 = 2）

**示例**（单位在 J10）：
```
J10 为中心格
1-1 范围（距离1）：I9, J9, K9, I10, J11, K11  ← 6 格
1-2 范围（距离2）：H8, I8, J8, K8, L8, I11, K12, L9, L10, H9, H10, I12  ← 12 格
总计 18 格
```

## 四、通用范围计算函数

### 4.1 getRadiusRange(oq, or, maxR, minR=0)

返回以 `(oq, or)` 为中心，距离在 `(minR, maxR]` 范围内的所有格子。

```javascript
function getRadiusRange(oq, or, maxR, minR = 0) {
  const s = new Set();
  for (let q = oq - maxR; q <= oq + maxR; q++) {
    for (let r = or - maxR; r <= or + maxR; r++) {
      const d = hexDistance(oq, or, q, r);
      if (d > minR && d <= maxR && q >= 0 && q < GRID_W && r >= 0 && r < GRID_H) {
        s.add(`${q},${r}`);
      }
    }
  }
  return s;
}
```

### 4.2 getMeleeRange(oq, or)

返回以 `(oq, or)` 为中心的相邻 6 格（距离 = 1）。

```javascript
function getMeleeRange(oq, or) {
  const s = new Set();
  for (const d of HEX_DIRS) s.add(`${oq + d.q},${or + d.r}`);
  return s;
}
```

### 4.3 getPolearmRange(oq, or)

返回以 `(oq, or)` 为中心的距离 1~2 的 18 格。

```javascript
function getPolearmRange(oq, or) {
  return getRadiusRange(oq, or, 2, 1);
}
```
