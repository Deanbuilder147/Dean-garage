## 五、词条库数据结构 (v3.0)

中枢配置: `services/combat-service/src/config/glossary-skill-config.json`

### 9 个已配置技能
`block` | `sweep` | `throw` | `execute` | `duel` | `snatch` | `focused_fire` | `lucky` | `reactivate`

### 通用结构化字段 (每技能必有)
| 字段 | 类型 | 说明 |
|------|------|------|
| `target_filter` | enum | enemy/ally/self/all |
| `cast_range` | number | 施放距离(BFS寻路) |
| `aoe_radius` | number | 0=单体, >0=溅射半径 |
| `base_damage` | number | 基础伤害值 |
| `status_effects` | string[] | burn/stun/disable/slow/poison/freeze |

### CRUD 数据流
```
添加 → saveConfig({ skills: { new_key: {...} } }) → deepMerge
删除 → pendingDeletes[] → saveConfig({ _delete_skills: [...] }) → deleteSkills()原子
修改 → 编辑通用字段 + 高级参数 → saveConfig → deepMerge
```

## 六、战棋开发终极宪法 v2.0 (三条红线)

1. **渲染管线沙盒化**: Canvas 是单向数据管道的终点，严禁主动读取 Vue ref/reactive
2. **坐标转换纯净化**: hexUtils.js 是唯一数学真理，禁止硬编码
3. **显式依赖与数据解耦**: 禁止无上下文幽灵函数

### 等距视角基准 (3D)
iso=ON, shearX=0.25, shearY=0.44, scaleX=1.00, scaleY=0.39, rot=-24
单元=64×72, 间距=H103% V79% O51%

### 3D 视角锁定策略
- **地图编辑器** (NewBattlefieldView): 保留滑块 +「💾 保存 3D 视角」按钮
- **战场端** (NewBattleView): 无滑块 UI，静默拉取 `_view` 配置
